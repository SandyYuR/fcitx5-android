# 支持与捐赠

靓企鹅·中州韵是个人兴趣维护的定制分支，**不设捐赠渠道**。

如果你觉得这个版本对你有帮助，更好的方式是把感谢送给让它成为可能的人：

## 支持上游与基线作者

- **[fxliang/fcitx5-android](https://github.com/fxliang/fcitx5-android)** —— 本分支的功能基线（浮动键盘、编辑器、主题、剪贴板同步等应用层能力都来自它的 fx 分支）。作者设有赞赏渠道，见 [fxliang 文档站的捐赠页](https://fxliang.github.io/fcitx5-android/about/donate)。
- **[上游 fcitx5-android/fcitx5-android](https://github.com/fcitx5-android/fcitx5-android)** —— Android 平台的 Fcitx5 主体框架。
- **[Rime](https://rime.im/)** —— 中州韵输入法引擎本身，以及众多方案与词典维护者。

对这些项目的 star、issue 反馈、文档改进和方案贡献，都是实在的支持。

## 反馈本分支

使用中遇到的问题请到 [SandyYuR/fcitx5-android/issues](https://github.com/SandyYuR/fcitx5-android/issues) 反馈，方式见 [反馈问题](/troubleshooting/report-issue)。
