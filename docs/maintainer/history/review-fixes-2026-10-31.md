## 验证记录

代码首批提交 `1d58fbbcc` 的 [Linux CI](https://github.com/SandyYuR/fcitx5-android/actions/runs/41162315598) 已完成：174 份 JUnit 报告、1,388 个用例，失败、错误、跳过均为零；ARM64 Debug 和原生依赖审计通过。该结果对应首批代码，不自动替代后续补充测试与语言资源提交。

网页编辑器 `4bfb202` 的 [Editor checks](https://github.com/SandyYuR/f5a-see-me/actions/runs/41163812081) 已通过 118 项 Node 测试及完整 Chromium 交互、几何回归，GitHub Pages 部署成功。首次接入 CI 时暴露的路由事件先后顺序已改为等待实际 Route 回调，未放宽图标请求去重断言。

Windows 验证中的符号链接能力不足与真实失败分开报告；不把本地跳过计作通过。原生动画、取消返回及 Android 画面最终以已启用的设备回归结果为准。没有运行的项目不会沿用旧报告的成功结论。

补充修复包含主题预览布局监听、草稿恢复与网格缩放回归，以及德、西、日、韩、俄语缺译。最后一轮本地验证为 176 份 JUnit 报告、1,390 个用例，零失败、零错误，29 个 Windows 符号链接用例因权限不足跳过；Lint 为零错误、681 条警告。ARM64 Debug、测试 APK、打包白名单和原生链接审计均已通过。修复分支的 Linux CI 继续要求所有用例零跳过。

设备门禁补跑发现并修正了两类夹具问题：原手势镜像缺少 SystemUI，不能接收系统边缘返回；原剪贴板页面测试没有提供记录 ID，触发了页面正确的关闭行为。手势矩阵改用完整镜像，剪贴板测试通过真实数据库记录打开页面并等待加载完成。完整镜像首次开机与编译并行时还出现桌面无响应，后续将编译前移，并在测试开始前验证桌面就绪；这些失败记录不计为验收成功。
