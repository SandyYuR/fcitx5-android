# 界面一致性复核 · 2026-11-06

本轮在应用 `ae4a13438`、文档 `4574079d5` 的基础上，按“与主界面风格统一”的要求复核共用组件和 AI 面板。方法参考用户提供的 [awesome-design-md](https://github.com/VoltAgent/awesome-design-md)，规则落在主代码分支 `DESIGN.md` 与[界面设计说明](../implementation/design-system)。

## 审阅与落实范围

| 区域 | 复核结果与修改 |
| --- | --- |
| 主界面、设置分组 | 以现有 `SettingsUiActivity` 的 Material 3 Expressive 色板、系统栏与卡片为基准 |
| 编辑器与表单 | 共用 12 dp 圆角输入样式，键盘编辑器保留兼容样式别名；默认 `MaterialSpinner` 与其一致 |
| AI 助手 | 从独立键盘配色改为主界面色板；标题、选择、输入、回复与主操作分层，细化深浅色和错误状态 |
| 窗口与操作 | 标题和主操作固定，中间滚动；极短窗口整体滚动；大字号完整按钮换行，不把操作挤出视区 |
| 连接信息 | 常态只显示主机和模型，长按可看完整接口；保留权限与请求检查 |
| 语音与方案菜单 | 复核已有主题包装和选择回调，继续共用现行主题入口 |
| 数据恢复 | 加载卡片和结果对话框使用资源 MD3 主题；保留独立进程、重试和恢复事务，不读取正在替换的偏好 |

内置助手适配版本为 `1.23.3-fx`。没有改动输入引擎、原编辑器的预览/确认/取消、网络授权或密钥保存流程。没有新增 UI 库、下载字体或运行时图片依赖。

## 常用页面的追加优化

| 区域 | 最终行为 |
| --- | --- |
| 主题库 | 预览、单行名称、一行编辑／导出按钮；不预留空白名称行或底部空行。标准字号卡片高 160 dp，按钮仍有 48 dp 触摸高度；日夜状态用角标，预览按卡片轮廓裁剪 |
| 主题列表更新 | 按主题名称保持选择；移除前面的条目或重命名其他主题时，当前／日间／夜间标记不漂移；以差量更新替代整表通知 |
| 插件设置 | 列表标明语音／工具能力；服务参数、密钥、权限分区，空分组随条件隐藏；选择项显示声明中的标签，存储仍使用原值 |
| 共用表单 | XML 输入框统一样式；剪贴板确认突出为主操作，`WrappingActionRow` 与 AI 共用完整按钮换行逻辑 |
| 剪贴板 | 短条目至少 48 dp，置顶标记与正文分开，保留敏感遮盖、分页、复制和保存顺序 |
| 导入与备份 | 真实阶段与结果保持可见，导入显示目标目录，失败可展开或重新打开详情；事务与确认流程不变 |
| 更新页 | 用原生图标表达下载、取消、安装与重试，统一状态颜色；版本获取失败后提供页面内重试 |
