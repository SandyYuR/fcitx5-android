## 记录约定

- 每轮核对新增一篇 `YYYY-MM-DD-*.md`，写明代码事实源、文档基线和查证边界；在本页与维护侧栏“代码与文档对照”登记。
- 逐提交核对同时提交 `commit-map-YYYY-MM-DD.json`：`base`、`head` 为完整 SHA，`commits` 按时间顺序到 `head` 结束，每行含 `sha`、`subject`、`files` 与 `documentation`（文档源文件路径）。`docs/scripts/check-doc-catalog.mjs` 会校验 SHA 格式、去重、末行等于 `head`，以及每个文档路径都是现行页面。
- 对照页记录的提交后来被改写或未留在默认分支时，在页首加引用块：`> **后续更正：** 现行代码为 <sha>，差异……`；已合入的分支记录用“后续复核”。原文与验证结论不改。
- 新增或改名现行功能页时同步[覆盖表](./feature-coverage)；文档迁移规则见[维护约定](/maintainer/documentation)。
