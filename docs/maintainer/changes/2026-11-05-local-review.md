## 本地开发链路

新增[Windows 本地引擎开发](../local-engine-development.md)。MSVC 和 Windows SDK 负责宿主数据工具，固定 NDK 负责 Android 库；源码依赖保持原有版本锁。开发构建纳入工作树快照，真实索引和 HEAD 保留。

开发 SDK 单独记录源树、ABI、来源和摘要；Gradle 必须显式选择，Release 被拒绝，取消选择后恢复正式锁。SDK 下载器测试覆盖损坏、ABI 缺失、开发/发行切换及 Release 防护。

## 性能范围

本次重复执行源码 → SDK → APK 链路约 78 秒，引擎 C++ 编译数为零，确认未改源文件的时间戳与 Ninja 增量构建继续有效。这是本机暖缓存记录，不是固定耗时承诺。

默认搜索改为约 1.04 MB 的现行索引，全集约 5.94 MB；按未压缩 JSON 计，默认下载量减少约 82%。浏览器网络记录确认未勾选历史时只取现行索引；历史仍可按需检索。键盘输入与关闭操作在分批恢复索引期间保持可用。

没有连接到 Android 设备，尚未执行真机冷重启、完整触摸矩阵、云端语音或实际设备性能对比。源代码审阅和 Debug 出包不代表这些场景已通过。
