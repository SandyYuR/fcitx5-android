## 功能与资源

- 水彩更新后含 126 个图标槽，普蓝含 71 个。同步工具栏、中英状态、Shift 三态、编辑键及作者提供的数字／字母图标；普蓝没有提供的字母／数字 SVG 保持文字显示。
- 工具栏支持单手、浮动、分体和语音的激活图标；语音继续兼容旧主题的 `system.voice_input` 槽。有道和 B 站图标只绑定对应的稳定插件／App ID。
- 两套配套布局新增 `editor`：26 列、4 行、15 个真实按键，左右方向键各跨前三行。支持方向重复、选择锁定、行首行尾、剪切复制粘贴、空格、退格和回车。
- 「文本编辑风格」内新增「文本编辑布局」，提供自动、内置常规布局和当前配置中的布局条目。Foxy 滑动风格继续单独读取六键 `text_editor` 底栏。
- 编辑预览使用同一跨行几何与原始行／键身份；修改按键并保存、重开时保留 `column`、`columnSpan`、`rowSpan`。两种编辑面板预览均不叠加合成态。
- 水彩主键盘更新为七键底行，补独立符号键、主空格槽与方向上滑提示；符号按钮的内联 SVG 提取为 `keys.symbols`。展开状态区使用作者「方案」图标，图标主题动作使用「布局预览」，编辑键盘左下返回使用独立紫色四点图。
- 两套数字页左右边列从 15.5% 调整为 15%，对齐主键盘的 Shift、数字切换、退格与回车；中间区域保持原比例分配。水彩 Home／End 复用编辑键盘行首／行尾图标，Page Up／Page Down 复用上下箭头的配色。
- 数字页采用作者的新排列；带图标槽的文字数字键可以显示 SVG，缺图时回到原标签。灰阶 SVG 保留两种以上灰色，等号／小数点不再被整枚染黑。共享图标字体更新为作者当前文件。
- 水彩表情／符号面板返回使用数字页紫色四点；返回与退格复用主数字切换键浅灰，选中分组使用主回车淡蓝与配对文字色。普蓝工具栏展开改用作者蓝狐狸「方案.svg」。
- 图标编辑器支持带 svg: 前缀、XML 声明和换行的 SVG 缩略图；无效图形只显示短摘要，直接确认保留原始图标值。
- 内置资源升级保留既有登记、当前代码基线和本轮旧安装包的已知字节数；修正旧跳过标记后可重试升级，集合外文件继续保留用户版本。未把错误尺寸登记成可覆盖的旧版本。

具体入口与配置语义见[文本编辑](/features/text-editor)、[布局编辑器](/features/editor/layout-editor)、[图标主题](/features/theme/icon-themes)与[成套主题](/features/theme/theme-editor)。
