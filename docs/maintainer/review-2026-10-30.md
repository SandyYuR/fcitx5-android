## fix 分支合入内容

| 类别 | 修复 |
| --- | --- |
| JS 语音 | 限制脚本会话资源、网络请求和数据队列；修复音频分片 Base64 拼接；处理取消、超时、插件覆盖与整包备份。 |
| 备份恢复 | 在 SQLite 内复制大条目，正确处理 WAL 状态，并覆盖大文本与二进制剪贴板数据。 |
| 剪贴板同步 | 按连接顺序处理消息并限制排队字节数，避免接收过载。 |
| 输入和主题性能 | 缓存符号过滤结果，减少主题启动工作和光标 UTF-16 转换开销。 |
| 增量构建 | 按资源相对路径跟踪变更，流式计算资源描述摘要。 |
| 授权弹窗 | 主题包装改为保留宿主窗口服务，修复撤销网络主机授权时 `BadTokenException`。 |

同时保留默认分支近期行为：WebSocket/HTTPS 主机授权按插件隔离、语音引擎选择器提供插件设置入口，长按语音工具栏按钮切换引擎，并独立显示收起键盘按钮。
