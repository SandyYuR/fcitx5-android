# QR 分享与导入

fx 引入了 **二维码 (QR Code) 分享机制**，让用户可在不依赖云端的情况下，轻松交换：

- 键盘布局
- Popup 预设
- 主题
- 等等

## 工作机制

1. **生成方**：在编辑器中点击 "分享" / "+ 菜单" → 生成 QR
2. **接收方**：在对应编辑器或扫码导入入口中使用 **相机扫码 / 从图片导入** 等方式导入

也可以使用电脑端的 [在线编辑器](https://fxliang.github.io/f5a-see-me/){target="_blank" rel="noopener"} 修改布局、Popup 预设或主题：在线编辑器可生成二维码给手机端导入，也可以导入手机端导出的二维码继续编辑。

由于布局/主题数据量可能较大，QR 数据采用分块策略：

- fx 已优化 QR 数据分块大小（避免单张二维码过密导致扫码失败）
- 多个二维码会按分块编号重组还原原始数据，不要求按顺序扫描
- 含 **预览图**：分享布局/主题时附带可视化预览，方便对方在导入前确认

## 入口

| 资源 | 分享入口 | 导入入口 |
|------|---------|---------|
| 布局 | 布局编辑器 → 分享 | 布局编辑器 / 键盘相关扫码入口 |
| 主题 | 主题编辑器 → "+ 菜单" → 分享 | 主题编辑器 / 主题相关扫码入口 |
| Popup 预设 | Popup 编辑器 → 分享 | Popup 编辑器扫码入口 |

## 扫码方式

- **相机扫码**：实时扫描他人屏幕显示的 QR
- **从图片导入**：从图库选择已保存的 QR 截图或长图
- **批量分块**：自动识别并拼接多张 QR

## 导入后的命名

- 导入时会带入 profile name（避免覆盖现有配置）
- 主题导入支持子目录组织，多编码 ZIP 也兼容

## 故障排除

- 扫码失败：尝试调亮屏幕、靠近摄像头、对齐取景框
- 拼接失败：确认同一批二维码已扫齐，或保存为图片走"扫描文件"流程
