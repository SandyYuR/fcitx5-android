# 主题编辑器

应用内 **主题编辑器** 可视化调整颜色、背景、按键样式，无需手改文件即可创建新主题。

<span id="主题列表与配置页"></span>

## 主题库与键盘样式

入口：**应用主页 → 外观 → 主题**。页面包含“主题库”和“键盘样式”两个标签，可预览键盘外观。

“键盘样式”页的边框、圆角、候选高亮、文本编辑及剪贴板卡片等参数对所有键盘主题生效；单个主题的颜色和图片在主题编辑器中修改。设置应用自身的配色仍使用独立的“设置界面外观”入口。

- **主题列表**：点击卡片即选用该主题；自定义主题卡片左下角有**导出**按钮、右上角有**编辑**按钮（长按卡片同样可以导出，两种方式等价）；内置主题没有可导出文件，不显示导出按钮；
- **键盘样式页**：可调按键边框、圆角、边距、水波纹、标点位置、导航栏背景，以及手动/亮色/暗色三档主题选择；其中**「标点位置」只作用于字母键的标点副标签**（下方 / 右上 / 上方居中 / 隐藏），**不会**影响回车、退格、大小写、符号、布局切换与 MacroKey 的划动标签与触发方向——那些只由布局配置决定（上滑在上、下滑在下），见[滑动操作](/features/keyboard/swipe-actions#分开配置上滑与下滑-swipeup-swipedown)；
- **工具栏候选栏高亮**：键盘样式页里还有**候选栏高亮圆角半径**（默认 4）与**候选栏高亮边距**（默认 8）两项，详见[候选窗增强](/features/candidate-window)；
- **编码区 / 工具栏圆角**（本版）：键盘样式页新增**编码区圆角半径**与**工具栏上方圆角半径**（均默认 0，范围 0–48dp）。两者配合可让编码区（预编辑）胶囊的底部与键盘卡片上方接成一条连续弧线——编码区圆角越大，胶囊底部两侧向外扩的弧越明显；
- **副标签存在时移动主字符**（本版）：键盘样式页开关，默认开。开启时按键主字符为副标签让位（副标签在下方时主字符上移）；关闭时主字符恒定居中，不随副标签位移。上下划标签都有而键高不足时，两个标签会**各占一个角**（上标签退右上、下标签退右下），不再只保留右上角而吞掉下滑标签。

## 随机主题（本版）

主题列表新增**随机主题**入口（工具栏或状态区的「**随机主题**」按钮）：一键生成随机配色并即时应用。**新装 / 升级后打开主题列表，随机主题卡片默认就在**（仅预生成并持久化槽位，**不会擅自切换你正在用的主题**）。

- 生成时从多种配色方案（同类 / 互补 / 三角 / 分裂互补 / 单色）随机取一套，并按**对比度 / 色相 / 饱和度 / 明度**四项算出一个 **0–100 的美学评分**；应用时会弹出提示（形如「随机主题：88/100（对比度 …，色相 …，饱和度 …，明度 …）」），随机主题卡片上也显示「评分 N/100」；
- 随机主题卡片上，左上角的随机图标与左下角的按钮都执行**重新随机**（`random_theme_generate`「重新随机」），重新生成并应用；右上角编辑按钮进入主题编辑器，可继续手动调色（改动会写回随机主题）；
- 编辑器菜单里的「**复制为自定义主题**」（`random_theme_copy`）把当前随机配色另存为可继续微调、可导出的自定义主题；
- 「**随机主题**」是**保留名称**（`random_theme_name_reserved`「此名称保留给随机主题使用」）：给主题命名时不能使用，随机主题本身也不能直接导出——先「复制为自定义主题」再导出。

## 颜色项语义分组（本版）

自定义主题编辑器的颜色项全部提供中文名称（整体背景、顶栏、按键背景、候选文字、水波纹效果等），并按语义分成五组折叠显示：

**背景与顶栏 / 按键 / 候选区 / 弹出与剪贴板 / 分隔线与选中态**。默认展开前两组，其余点分组标题展开或收起。颜色项名称与分组只用于显示，不会写进主题文件——升级后已保存的主题不受影响。

## 核心能力

编辑已有图片主题时，图片在后台按显示尺寸读取。修改后的图片使用独立文件保存，主题定义在最后发布；保存失败会保留原主题并停留在编辑器中，可重试。

普通主题的未保存颜色、名称和裁剪草稿会随页面重建恢复。返回时可选择保存、放弃或继续编辑；正在保存时请等待完成。随机主题继续使用原有的即时更新方式，另存为自定义主题后再按普通主题编辑。

- 可视化色板（含 HSV 编辑器）
- 背景图导入 / 缩略图预览；壁纸解码移出主线程、只解一次
- 按键圆角、波纹效果（可自定义颜色）
- Gboard 风格圆角 action key；borderless 模式修正
- 子目录主题组织；多编码 ZIP 导入（兼容 Windows GBK 等编码）
- 主题包读取与解压有**条目与总量限额**并校验条目路径，防御恶意包

## 内置主题

首次启动时，应用会自动安装一批社区贡献的键盘主题（「森林集·write」「长日将烬」「isGboard」「WeChat Dark/WeChat Light」「Braun Minimal Dark/Light」「Caramel Dawn/Caramel Ember」「GitHub Dark Dim」「Sage Journey」等），可直接选用；**删除后不会被再次自动安装**。内置主题内容更新时只替换从未被用户修改过的文件。

## 入口

- **应用主页 → 外观 → 主题**：对已有主题卡片点 **编辑** 进入编辑器；键盘样式页管理全局显示参数
- 也可以在电脑浏览器中使用 [在线编辑器](https://sandyyur.github.io/f5a-see-me/){target="_blank" rel="noopener"} 修改主题，再通过二维码导入到手机端。

## 按键水波纹透明度

按键水波纹遵循主题颜色自身的 alpha 透明度，半透明颜色不会被强制画成不透明；完全透明时不显示水波纹。修改颜色后可在普通输入框按键观察效果。
