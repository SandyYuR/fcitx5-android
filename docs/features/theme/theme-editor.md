# 主题编辑器

应用内 **主题编辑器** 可视化调整颜色、背景、按键样式，无需手改文件即可创建新主题。

<span id="主题列表与配置页"></span>

## 主题库与键盘样式

主题列表按屏幕宽度调整列数，上下边距与行间距保持 16 dp；窄屏单列也保持紧凑排列。

入口：**应用主页 → 外观 → 主题**。页面包含“主题库”和“键盘样式”两个标签，可预览键盘外观；预览使用当前启用布局的默认排列，布局里逐键配置的颜色也会显示，与真实键盘一致。

“键盘样式”页的边框、圆角、候选高亮、文本编辑及剪贴板卡片等参数对所有键盘主题生效；单个主题的颜色和图片在主题编辑器中修改。设置应用自身的配色仍使用独立的“设置界面外观”入口。

- **主题列表**：卡片上方预览键盘颜色，下方为“名称一行、按钮一行”，不预留空白行；长名称保持单行省略，可长按名称查看完整提示。右上角用“使用中／日间／夜间”标记当前选择。点击卡片选用主题，自定义主题的**导出**和**编辑**入口统一放在底部（长按预览区仍可导出）；内置主题没有可导出文件，不显示导出按钮。名称、操作和新增卡片跟随设置界面配色，预览保留各主题的颜色；高度随字号调整。
- **键盘样式页**：可调按键边框、圆角、边距、水波纹、标点位置、导航栏背景，以及手动/亮色/暗色三档主题选择；其中**「标点位置」只作用于字母键的标点副标签**（下方 / 右上 / 上方居中 / 隐藏），**不会**影响回车、退格、大小写、符号、布局切换与 MacroKey 的划动标签与触发方向——那些只由布局配置决定（上滑在上、下滑在下），见[滑动操作](/features/keyboard/swipe-actions#分开配置上滑与下滑-swipeup-swipedown)；
- **工具栏候选栏高亮**：键盘样式页里还有**候选栏高亮圆角半径**（默认 4）与**候选栏高亮边距**（默认 8）两项，详见[候选窗增强](/features/candidate-window)；
- **编码区 / 工具栏圆角**（本版）：键盘样式页新增**编码区圆角半径**与**工具栏上方圆角半径**（均默认 0，范围 0–48dp）。两者配合可让编码区（预编辑）胶囊的底部与键盘卡片上方接成一条连续弧线——编码区圆角越大，胶囊底部两侧向外扩的弧越明显；
- **副标签存在时移动主字符**（本版）：键盘样式页开关，默认开。只有单个副标签时，开启可让主字符为副标签让位（副标签在下方时主字符上移）；关闭时主字符恒定居中。同时存在上下两个划动标签时，开关两种状态的显示一致：主字符居中，上下标签分别在对应方向居中。键高过小时仍使用双角落紧凑布局（上标签退右上、下标签退右下），不会因为开启开关而提前靠边。文字键和图标键遵循同一规则。
- **副标签显示在侧边**（本版）：键盘样式页开关，默认关。开启后上下滑副标签不再画在按键上方／下方，而是**固定贴在按键侧边**——上标签贴侧边上角、下标签贴侧边下角；「**副标签侧边位置**」可选**右侧**（默认）或**左侧**，开关关闭时该项置灰。字母键的标点副标签与方向性划动标签都跟随：标点位置选「右上」「上方居中」时上标签改贴侧边上角，选「下方」时下标签改贴侧边下角，选「隐藏」仍然隐藏。**滑动方向不变**（上滑仍是上滑、下滑仍是下滑），只有显示位置改变；关闭开关后恢复原来的上方／下方布局。
- **显示按键副标签**（本版）：键盘样式页开关，默认开。关闭后所有按键副标签（字母键的标点提示、回车／退格／大小写／布局切换的划动标签）都不再绘制，也不占位；主字符与图标按键的图标保持原样。字母键在图标主题里配了 `keys.letter.*` 槽位时，图标在下、副标签在上叠加显示，关闭本开关即只留图标。开关即时生效，不重建键盘，随主题设置一起保存。

## 随机主题（本版）

主题列表新增**随机主题**入口（工具栏或状态区的「**随机主题**」按钮）：一键生成随机配色并即时应用。**新装 / 升级后打开主题列表，随机主题卡片默认就在**（仅预生成并持久化槽位，**不会擅自切换你正在用的主题**）。

- 生成时从多种配色方案（同类 / 互补 / 三角 / 分裂互补 / 单色）随机取一套，并按**对比度 / 色相 / 饱和度 / 明度**四项算出一个 **0–100 的美学评分**；应用时会弹出提示（形如「随机主题：88/100（对比度 …，色相 …，饱和度 …，明度 …）」），随机主题卡片上也显示「评分 N/100」；
- 随机主题卡片底部的骰子图标执行**重新随机**，与编辑按钮排列在同一行；编辑按钮进入主题编辑器，可继续手动调色（改动会写回随机主题）。随机主题卡片不显示导出按钮。
- 名称保持单行，按钮行收紧显示高度并向上扩展点击范围，减少留白；选中状态仍以独立角标展示。工具栏的随机主题图案由当前[图标主题](/features/theme/icon-themes)控制。
- 编辑器菜单里的「**复制为自定义主题**」（`random_theme_copy`）把当前随机配色另存为可继续微调、可导出的自定义主题；
- 「**随机主题**」是**保留名称**（`random_theme_name_reserved`「此名称保留给随机主题使用」）：给主题命名时不能使用，随机主题本身也不能直接导出——先「复制为自定义主题」再导出。

## 颜色项语义分组（本版）

自定义主题编辑器的颜色项全部提供中文名称（整体背景、顶栏、按键背景、候选文字、水波纹效果等），并按语义分成五组折叠显示：

**背景与顶栏 / 按键 / 候选区 / 弹出与剪贴板 / 分隔线与选中态**。默认展开前两组，其余点分组标题展开或收起。颜色项名称与分组只用于显示，不会写进主题文件——升级后已保存的主题不受影响。

符号、表情和颜文字面板的当前分类使用“分隔线与选中态”中的**选中项背景**与**选中项文字**。两项成对设置，例如白色背景配深绿色文字；分类文字独立于“强调按键文字”。左侧分组栏与底部栏使用同一配色规则。

## 核心能力

编辑已有图片主题时，图片在后台按显示尺寸读取。修改后的图片使用独立文件保存，主题定义在最后发布；保存失败会保留原主题并停留在编辑器中，可重试。

普通主题的未保存颜色、名称和裁剪草稿会随页面重建恢复。返回时可选择保存、放弃或继续编辑；正在保存时请等待完成。随机主题继续使用原有的即时更新方式，另存为自定义主题后再按普通主题编辑。

- 可视化色板（含 HSV 编辑器）
- 背景图导入 / 缩略图预览；壁纸解码移出主线程、只解一次
- 按键圆角、波纹效果（可自定义颜色）
- Gboard 风格圆角 action key；borderless 模式修正
- 子目录主题组织；多编码 ZIP 导入（兼容 Windows GBK 等编码）
- 主题包读取与解压有**条目与总量限额**并校验条目路径，防御恶意包

## 成套主题

部分内置主题带配套的键盘布局、图标主题与按键副字体。点这类主题卡片时，如果配套资源还没有全部就位，会先问「一并应用」还是「仅应用配色」：

- **一并应用**：按布局 → 图标主题 → 按键副字体 → 操作键形状 → 配色的顺序换上，一次刷新就是成套效果，不会先出现新布局配旧配色。水彩与普蓝会关闭「使用 Gboard 风格的操作按键」，改用圆角矩形操作键，之后仍可在键盘样式页改回；
- **仅应用配色**：只换配色，布局、图标主题与字体都保持不动。

配套已经全部就位时不再弹框，点卡片直接应用。成套主题的卡片左上角有与莫奈主题相同的星标。成套关系按主题名登记，主题被复制或改名后不再成套。

当前成套的内置主题有两套，每套都带主键盘、数字层与文本编辑栏三种形态：

## 内置主题

首次启动时，应用会自动安装一批社区贡献的键盘主题（「水彩」「普蓝」「森林集·write」「长日将烬」「isGboard」「WeChat Dark/WeChat Light」「Braun Minimal Dark/Light」「Caramel Dawn/Caramel Ember」「GitHub Dark Dim」「Sage Journey」等），可直接选用。内置主题文件被删除后，**下次启动会按原名重新补装**；内置主题内容更新时只替换从未被用户修改过的文件。

## 入口

- **应用主页 → 外观 → 主题**：对已有主题卡片点 **编辑** 进入编辑器；键盘样式页管理全局显示参数
- 也可以在电脑浏览器中使用 [在线编辑器](https://sandyyur.github.io/f5a-see-me/){target="_blank" rel="noopener"} 修改主题，再通过二维码导入到手机端。

## 按键水波纹透明度

按键水波纹遵循主题颜色自身的 alpha 透明度，半透明颜色不会被强制画成不透明；完全透明时不显示水波纹。修改颜色后可在普通输入框按键观察效果。
