# 主题编辑器

::: warning 待补充
本页内容正在撰写修订中。
:::

fx 提供应用内 **简易主题编辑器**，可视化调整颜色、背景、按键样式，无需手改文件即可创建新主题。

## 核心能力

- 可视化色板（含 HSV 编辑器）
- 背景图导入 / 缩略图预览
- 按键圆角、波纹效果（可自定义颜色，见 [波纹与按键样式]）
- 子目录主题组织
- 多编码 ZIP 导入（兼容 Windows GBK 等编码）
- 重命名安全的背景资产
- 编辑无变更时打开取色器的崩溃修复

## Gboard 风格

fx 增加了 Gboard 风格的圆角 action key 选项。

## 边距与边框

- borderless 模式与 Gboard 风格下的主题修正
- 边距、按键间距独立配置

## 入口

进入 **配置 → 主题 → 创建新主题** 或对已有主题点击 **编辑**。

也可以在电脑浏览器中使用 [在线编辑器](https://fxliang.github.io/f5a-see-me/){target="_blank" rel="noopener"} 修改主题，再通过二维码导入到手机端。
