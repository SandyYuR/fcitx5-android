# 主题编辑器

应用内 **主题编辑器** 可视化调整颜色、背景、按键样式，无需手改文件即可创建新主题。

## 主题列表与配置页

入口：**应用主页 → 外观 → 主题**。页面包含主题列表和配置页，可预览键盘外观。

- **主题列表**：点击卡片即选用该主题；自定义主题卡片左下角有**导出**按钮、右上角有**编辑**按钮（长按卡片同样可以导出，两种方式等价）；内置主题没有可导出文件，不显示导出按钮；
- **配置页**：可调按键边框、圆角、边距、水波纹、标点位置、导航栏背景，以及手动/亮色/暗色三档主题选择；
- **工具栏候选栏高亮**：配置页里还有**候选栏高亮圆角半径**（默认 4）与**候选栏高亮边距**（默认 8）两项，详见[候选窗增强](/features/candidate-window)。

## 颜色项语义分组（本版）

自定义主题编辑器的颜色项全部提供中文名称（整体背景、顶栏、按键背景、候选文字、水波纹效果等），并按语义分成五组折叠显示：

**背景与顶栏 / 按键 / 候选区 / 弹出与剪贴板 / 分隔线与选中态**。默认展开前两组，其余点分组标题展开或收起。颜色项名称与分组只用于显示，不会写进主题文件——升级后已保存的主题不受影响。

## 核心能力

- 可视化色板（含 HSV 编辑器）
- 背景图导入 / 缩略图预览；壁纸解码移出主线程、只解一次
- 按键圆角、波纹效果（可自定义颜色）
- Gboard 风格圆角 action key；borderless 模式修正
- 子目录主题组织；多编码 ZIP 导入（兼容 Windows GBK 等编码）
- 主题包读取与解压有**条目与总量限额**并校验条目路径，防御恶意包

## 内置主题

首次启动时，应用会自动安装一批社区贡献的键盘主题（「森林集·write」「长日将烬」「isGboard」「WeChat Dark/WeChat Light」「Braun Minimal Dark/Light」「Caramel Dawn/Caramel Ember」「GitHub Dark Dim」「Sage Journey」等），可直接选用；**删除后不会被再次自动安装**。内置主题内容更新时只替换从未被用户修改过的文件。

## 入口

- **应用主页 → 外观 → 主题**：对已有主题卡片点 **编辑** 进入编辑器；配置页管整体样式参数
- 也可以在电脑浏览器中使用 [在线编辑器](https://sandyyur.github.io/f5a-see-me/){target="_blank" rel="noopener"} 修改主题，再通过二维码导入到手机端。
