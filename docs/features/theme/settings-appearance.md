# 设置界面外观与动画

本页适用于采用 Material 3 设置界面的版本。旧版本没有以下入口时，请先更新应用。

## 找到入口

打开 **设置首页 → 外观**：上方的「键盘外观」分组包含主题、图标主题和字体设定；最下方的「设置界面」分组中有 **设置界面外观**。

- **设置界面外观**调整应用设置页、应用自有编辑器外壳和首次启动引导的配色。
- **外观 → 主题**调整实际键盘与候选区的配色，详见[主题编辑器](/features/theme/theme-editor)和[键盘 Monet 映射](/features/theme/monet)。

首页搜索也可以查找「设置界面外观」「动画」「返回手势」并跳转到对应位置。

## 设置界面配色

| 选项 | 作用 |
| --- | --- |
| 主题模式 | 跟随系统、浅色、深色 |
| 纯黑深色背景 | 仅在深色模式生效；页面使用纯黑底色，卡片仍保留层次 |
| 跟随键盘主题配色 | 默认关闭；开启后从当前键盘的强调色、按键色、背景色生成设置配色，关闭后恢复原来的 Monet／手动选择 |
| 动态取色 | 在支持系统动态色的设备上跟随壁纸配色；关闭后恢复上次手动配色 |
| 颜色系列 | 关闭键盘取色和动态取色后，可选兼容紫、海盐、松林、莓果、琥珀、紫藤、石墨 |
| 配色风格 | 手动配色可选 CMF · 2026、柔和 · 2025、鲜明 · 2025、中性 · 2025、表现力 · 2025、经典 · 2021 |
| 对比度 | 键盘取色和手动配色可选标准、中、高三档 |

动态取色通常需要 Android 12 及以上，并取决于设备是否提供支持。系统动态色下不显示手动色系、风格和对比度选项；不支持动态色的设备仍可使用手动配色。

新安装会在设备支持时使用系统动态色；旧安装保留兼容配色，可以在这里主动切换。

### 让设置页与键盘更协调

开启 **跟随键盘主题配色**，查看预览并点 **应用**。此选项需要 Android 11 及以上；不依赖设备的壁纸动态色支持。

- 取色来源是当前实际启用的键盘主题，包含键盘自身的浅深色切换、随机主题和自定义 Monet 映射。
- 开启后暂时隐藏系统动态取色、手动色系和配色风格；原选择仍会保留，关闭后恢复。
- 设置页仍遵循自己的主题模式、纯黑背景与对比度选项。颜色按 MD3 的前景和容器角色生成，保留主题色相，同时保证文字和按钮的可读性。
- 在主题页切换键盘主题后，设置页会自动更新；从其他页面或输入法返回设置时也会同步。应用自有编辑器下次打开时使用当前配色，编辑过程中保留正在编辑的内容。
- 此选项不会修改键盘主题。背景图片不参与取色，图片主题使用其配置的颜色。

### 预览与应用

1. 修改选项后，先查看页面顶部的配色预览。
2. 点右上角 **应用** 保存，并将主题应用到实际界面。
3. 未点「应用」就离开外观页，会放弃本次未应用的外观草稿。

「恢复默认外观」也先改变草稿，需要再点「应用」。它只恢复设置界面外观，不会重置键盘主题或动画选项。

## 动画与返回手势

入口是 **外观 → 设置界面外观 → 动画与返回手势**。外观分组外层没有重复的动画入口。

| 选项 | 可选内容 |
| --- | --- |
| 前进动画 | 横向共享轴、纵向共享轴、缩放共享轴、淡入淡出、无动画 |
| 返回动画 | 跟随前进动画，或单独选择上述样式 |
| 动画速度 | 快速 350 ms、标准 500 ms、舒缓 650 ms |
| 预测性返回预览 | Android 14 及以上提供开关；拖动系统返回手势时预览上一页 |

这些选项**修改后立即保存**，不需要回到外观页点「应用」。默认使用横向前进、返回跟随前进、标准 500 ms；支持的系统上默认开启预测性返回预览。

- 返回样式同时用于返回键与手势预览，实际表现还受系统动画缩放和设备手势设置影响。
- 前进、返回都设为「无动画」时，速度选项不适用；返回设为「无动画」时，预测性返回预览控件不可用。
- 旧系统会显示预测性返回的版本要求，普通返回仍可使用。
- **恢复默认动画**会立即恢复动画与手势选项，不修改外观配色。

此前测试版本中的 180 / 300 / 450 ms 会按快速 / 标准 / 舒缓档位迁移为 350 / 500 / 650 ms，不需要重新选择。

## 首次启动引导与帮助

首次引导仍是 **启用输入法 → 选择输入法** 两步，显示步骤进度与完成状态，并采用相同的设置界面主题。跳转到系统设置、输入法选择器时，系统页面的外观由 Android 和设备厂商控制。

首页右上角 **更多 → 常见问题** 会打开[本项目文档站](/)。安装、方案配置与故障排查可继续查看[快速上手](/guide/quick-start)和[常见问题](/troubleshooting/faq)。
