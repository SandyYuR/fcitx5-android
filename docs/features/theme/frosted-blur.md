# 磨砂按键

::: warning 待补充
本页内容正在撰写修订中。
:::

**Frosted Key Blur** —— fx 引入的按键磨砂模糊效果，让按键呈现毛玻璃质感，配合自定义背景图效果尤佳。

## 能力

- 高斯模糊半径可调
- 预览与实际渲染保持一致（预览同步修复）
- 与背景图、Monet 主题协同

## 注意事项

- 模糊渲染会消耗一定 GPU 资源，低端设备可能感受到延迟
- 半透明键面下文字对比度需配合主题色调整
