# 磨砂按键

**Frosted Key Blur** —— 按键磨砂模糊效果，让按键呈现毛玻璃质感；只在带自定义背景图的主题上生效。

## 入口

在自定义主题编辑器中设置背景图后，调整「**背景模糊半径**」：范围 0–25，0 显示为「无模糊」。没有背景图的主题（包括 Monet 主题与随机主题）不显示这一项，也不产生磨砂效果。

## 能力

- 高斯模糊半径可调；按键区域显示模糊后的背景图，亮度沿用背景图亮度设置
- Android 12 及以上使用 GPU 模糊，更早的系统先在后台生成模糊位图再绘制
- 预览与实际渲染保持一致（预览同步修复）
- 模糊区域重建收敛为**有界重试**、每键一次裁剪一次绘制（本版性能加固，避免异常输入下反复重建）

## 注意事项

- 模糊渲染会消耗一定 GPU 资源，低端设备可能感受到延迟
- 半透明键面下文字对比度需配合主题色调整
