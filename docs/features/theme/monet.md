# Monet 编辑器

利用 Android 12+ 系统的 **Monet 动态取色** 生成键盘主题，让键盘色调自动跟随系统壁纸 / 主题色变化。

## 能力

- 一键基于当前系统 Monet 色板生成主题
- 可在生成后微调各颜色映射
- **一键恢复 Monet 默认配色映射**（本版，误调之后不必逐项改回）
- 提供预览与实时同步

## 门禁提示（本版）

MonetLight 和 MonetDark 卡片的预览左上角显示**星星形动态取色图标**，表示该主题支持自定义颜色映射；未选中时也会显示。它与右上角的选中／日间／夜间标记独立，底部编辑按钮用于调整映射。不支持自定义取色的设备不显示星星和编辑按钮。

## 兼容性

- Android 12 (API 31) 及以上
- 部分厂商 ROM 的 Monet 实现可能略有差异
