# Monet 编辑器

::: warning 待补充
本页内容正在撰写修订中。
:::

利用 Android 12+ 系统的 **Monet 动态取色** 生成键盘主题，让键盘色调自动跟随系统壁纸 / 主题色变化。

## 能力

- 一键基于当前系统 Monet 色板生成主题
- 可在生成后微调
- 提供预览与实时同步

## 兼容性

- Android 12 (API 31) 及以上
- 部分厂商 ROM 的 Monet 实现可能略有差异
