# Monet 编辑器

利用 Android 12+ 系统的 **Monet 动态取色** 生成键盘主题，让键盘色调自动跟随系统壁纸 / 主题色变化。

## 能力

- 内置 MonetLight、MonetDark 两套主题，颜色取自系统动态色，随壁纸 / 系统主题色变化
- 点卡片底部的编辑按钮，为每个主题颜色项（背景、按键、候选文字等）选择一个系统动态色资源；水波纹颜色可单独选资源，默认「Auto」自动计算
- **一键恢复 Monet 默认配色映射**（本版，右上角恢复按钮，误调之后不必逐项改回）
- 顶部键盘预览随选择即时更新；点右上角 ✓ 才保存映射，直接返回不保存
- 需要固定配色时，可在主题库新增卡片中选「复制内置主题」，把 Monet 主题复制为普通自定义主题

## 门禁提示（本版）

MonetLight 和 MonetDark 卡片的预览左上角显示**星星形动态取色图标**，表示该主题支持自定义颜色映射；未选中时也会显示。它与右上角的选中／日间／夜间标记独立，底部编辑按钮用于调整映射。不支持自定义取色的设备不显示星星和编辑按钮。

## 兼容性

- Android 12 (API 31) 及以上
- 部分厂商 ROM 的 Monet 实现可能略有差异
