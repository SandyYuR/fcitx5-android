# 文本编辑与底部栏

::: info 与「文本编辑器插件」的区别
fxliang fx 分支曾提供一个独立的 **文本编辑器插件 APK**（应用内打开/编辑文本文件）。该插件在 Rime-only 版中已随插件框架一并移除。本页描述的是键盘上的**文本编辑面板**，用于操作当前输入框中的文字。若你在旧版资料中看到「文本编辑器插件」，不适用于本版。
:::

**文本编辑**提供光标移动、选择、剪切、复制和粘贴等操作；工具栏（Kawaii Bar）上的光标按钮可直接打开面板。风格、常规编辑布局和 Foxy 手势参数都在 **应用主页 → 便捷功能 → 文本编辑** 中设置。

## 文本编辑风格

- **默认风格（Default）**：使用当前布局文件中的常规编辑布局；没有可用布局时显示内置文本编辑面板。水彩和普蓝配套布局带有四行编辑键盘。
- **Foxy 滑动风格**：使用触控板式光标和 `text_editor` 底部栏。按住光标键滑动可移动光标；长按先进入选取模式，继续滑动选择文字，松开结束选取。

切换风格或布局后，重新打开文本编辑面板查看变化。

## 选择常规文本编辑布局

在默认风格下打开 **文本编辑布局**，可选择当前布局文件里的任意布局或子布局，也可使用自动识别或内置面板：

| 选择 | 行为 |
| --- | --- |
| 自动（偏好值留空） | 优先使用当前基线布局下的编辑层，再找独立的 `editor` 等编辑布局，最后使用其他基线下唯一的编辑层；自动发现排除保留给 Foxy 的 `text_editor`。无匹配或结果歧义时使用内置面板 |
| 内置常规布局（`@builtin`） | 固定使用内置面板 |
| 当前布局文件中的指定条目 | 使用该条目，包括显式指定 `text_editor`；条目删除、无法解析或布局无效时，重新自动识别，再回退到内置面板 |

例如，`rime:__layer__:编辑` 可指定 `rime` 下的编辑层，`editor` 可指定独立编辑布局。选择只在当前布局文件中查找；切换布局文件后，旧条目不存在就按上述规则回退。多个其他基线都提供编辑层时，自动模式不会任意挑选其中一个。

设置页的 **编辑文本编辑布局** 在默认风格下打开显式选中的文件布局，或按自动识别结果定位布局；若选择内置或自动没有匹配项，则打开 `text_editor` 作为可编辑目标。Foxy 风格也固定编辑 `text_editor`，但运行面板始终不读取常规布局选项。内置面板本身不保存在布局文件中。按键、顺序、图标和配色可在[键盘布局编辑器](/features/editor/layout-editor#常规文本编辑布局)中调整。

水彩和普蓝内置的 `editor` 采用 **26 列、4 行、15 键**网格：左、右方向键各跨前三行，中间依次为上、选择、下；右侧是全选、剪切、复制、粘贴、行首、行尾，底行提供返回字母键盘、空格、退格和回车。长按方向键会重复移动；点击“选择”锁定选择后，方向键及行首、行尾键会扩展选区，再次点击“选择”可取消。

## Foxy 滑动风格参数

只有选了 Foxy 滑动风格，以下几项才可编辑：

| 设置 | 默认 | 范围 | 说明 |
|------|------|------|------|
| Foxy 光标移动步长 | 18dp | 4–80dp | 滑动多少距离移动一格光标，调小更细腻、调大更快 |
| Foxy 长按选取延迟 | 300ms | 100–1200ms | 按住多久进入选取模式；手速快就调小，容易误触选字就调大 |
| 四条提示文案 | 内置文字 | —— | 触控板上显示的手势提示语（移动 / 长按 / 选取中 / 松开结束选取），留空用内置 |

Foxy 始终读取 `text_editor` 底部栏，**不受“文本编辑布局”选项影响**。

## 自定义底部栏按键

Foxy 底部栏有哪些键、键的顺序与宽度，由 **`text_editor` 布局**决定：

- 入口一：选择 Foxy 滑动风格后，点击 **便捷功能 → 文本编辑 → 编辑文本编辑布局**；
- 入口二：**键盘 → 键盘布局自定义** 里的 `text_editor` 布局——两边进的是同一份文件。

编辑器预览与键盘共用按键解析，文本编辑面板只执行自身支持的按键动作。修改受支持的按键不需要改代码。

`text_editor` 运行时不支持[StickyModifierKey 粘滞修饰键](/features/keys/sticky-modifier-key)，类型下拉框不会提供新增选项。旧布局或恢复草稿中的已有类型会保留为禁用选项，保存该按键前必须明确改为受支持的类型；保留旧值不表示底部栏已支持执行它。
