# 文本编辑器插件

::: warning 待补充
本页内容正在撰写修订中。
:::

fx 提供 **文本编辑器插件**，让你在 Fcitx5 应用内直接打开 / 编辑文本文件，无需切换到其他编辑器。

## 能力

- 应用内打开任意可访问的文本文件
- **大文件处理**：针对大文件优化加载流程，避免一次性载入内存
- **低内存场景**：低内存设备上的容错与降级渲染
- 与 Fcitx5 自身的输入法天然衔接（编辑器即输入法测试场）

## 使用场景

- 调试自定义布局 JSON、主题 JSON、Rime 配置时的便捷查看
- 临时记事
- 验证某个键盘布局的输入效果

## 已知限制

- 非完整 IDE 体验（不支持复杂语法高亮、调试等）
- 二进制文件不支持
