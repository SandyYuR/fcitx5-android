# 文本编辑底部栏

::: info 与「文本编辑器插件」的区别
fxliang fx 分支曾提供一个独立的 **文本编辑器插件 APK**（应用内打开/编辑文本文件）。该插件在 Rime-only 版中已随插件框架一并移除。本页描述的是键盘上的**文本编辑底部栏**——一个完全不同、且本版完整保留的功能。若你在旧版资料中看到「文本编辑器插件」，不适用于本版。
:::

**文本编辑**是键盘上那排 **光标移动 / 选择 / 剪切复制粘贴** 按键所在的底部栏；工具栏（Kawaii Bar）上的光标按钮也会直接打开它。它的风格、手势参数与提示文案都可以在设置中调整。

路径：**应用主页 → 便捷功能 → 文本编辑**。

## 文本编辑风格

- **默认**：传统底部栏——一排文本编辑按键；
- **Foxy 滑动风格**：换成 Foxy 输入法那种**触控板式光标**——**按住光标键滑动即可移动光标**；**长按先进入选取模式**，之后继续滑动就是选中文字，松开结束选取。

切换风格后需要打开一次文本编辑底部栏才会看到变化。

## Foxy 滑动风格参数

只有选了 Foxy 滑动风格，以下几项才可编辑：

| 设置 | 默认 | 范围 | 说明 |
|------|------|------|------|
| 光标移动步长 | 18dp | 4–80dp | 滑动多少距离移动一格光标，调小更细腻、调大更快 |
| 长按选取延迟 | 300ms | 100–1200ms | 按住多久进入选取模式；手速快就调小，容易误触选字就调大 |
| 四条提示文案 | 内置文字 | —— | 触控板上显示的手势提示语（移动 / 长按 / 选取中 / 松开结束选取），留空用内置 |

## 自定义底部栏按键

底部栏上有哪些键、键的顺序与宽度，全部由 **`text_editor` 布局**决定：

- 入口一：**便捷功能 → 文本编辑 → 编辑 Foxy 底部布局**；
- 入口二：**键盘 → 键盘布局自定义** 里的 `text_editor` 布局——两边进的是同一份文件。

编辑器里的预览与真机键盘用的是同一套按键解析，所以编辑器里是什么样，真机上就是什么样。改它不需要改代码。
