# JS 插件：语音、AI 助手与文本工具

JS 插件把语音识别或文本处理逻辑写在一个 `.js` 文件中，在输入法内置 QuickJS 中运行。语音引擎使用 `voice.asr`；带界面的文本工具使用 `foxy.app.register(...)`。

::: info AI 功能版本
AI 助手、JS App 界面和动态端点授权已于 2026-11-05 合入默认分支 `fx-rime-only`。较早的 APK 需更新后使用；语音插件的配置仍见下文。
:::

新版接口手册：[中文完整参考](./voice-input-js-reference-zh-CN) · [English reference](./voice-input-js-en)。两份参考均已按本次提供的 `js-plugin-README.md` 更新；原版 Foxy 与中州鹅的差异在页首标注。

## 从这里开始

插件列表以“语音／工具”说明能力，并保留版本、来源及首选标记。设置页分为“服务参数”“密钥”“授权管理”和“插件管理”；切换服务或鉴权方式后只显示相关字段，空分组自动隐藏。顶部密钥计数仅表示当前显示字段的保存状态，不代表账号或服务已联网验证。普通设置仍即时保存，密钥不回填到输入框。

1. 打开 **设置 → 输入与候选 → 语音输入 → JS 插件设置**（旧版名称为“语音插件设置”）。
2. 选择一个插件，填写它所需的普通参数和密钥。
3. 核对并批准该插件声明的完整网络主机清单。内置插件同样需要授权。
4. 在“首选语音输入”选择它，授予录音权限，在普通输入框点击语音按钮测试。

工具栏语音按钮短按开始识别，长按打开引擎选择器；JS 项旁的设置入口可直接打开对应插件。隐藏语音按钮后仍能在设置中选择首选引擎。
语音按钮可在工具栏配置中调整位置、图标和动作，收起键盘按钮独立保留；密码框不会显示语音按钮。

## 四个内置语音插件

| 插件 | 使用方式 | 需要准备 |
| --- | --- | --- |
| 通义千问 `qwen-asr` | 实时流式或单次请求 | 对应服务的 API key，按所选模式配置模型与端点 |
| 豆包 `doubao-asr` | 火山引擎流式或单次结果 | 新版 API key，或旧版 access token 与 App ID；核对资源授权 |
| 腾讯云识别 `tencent-asr` | 实时语音识别 | AppID、SecretId、SecretKey |
| 腾讯云翻译 `tencent-translate` | 实时语音识别与翻译，按插件选项输出 | AppID、SecretId、SecretKey，以及源语言、目标语言和模型 |

内置脚本不附送云端账号或服务额度。账号权限、模型可用性和计费由对应服务管理。
腾讯云插件的 AppID 应填项目的 **10 位 APPID**，不是 **12 位账号 ID（UIN）**。
豆包切换鉴权方式时会联动资源 ID：新版 `X-Api-Key` 默认使用 2.0 小时版，旧版鉴权默认使用 1.0 小时版；仍应按自己账号已授权的资源调整。

## AI 助手

详细的三协议、端点、授权和取消行为见 [AI 文本助手完整说明](./ai-assistant)。

AI 助手可从 **设置 → 便捷功能 → JS 插件设置 → AI 助手** 配置；语音输入页中的同名插件设置入口仍保留。插件列表的 **AI 按钮使用的助手** 可选择内置或导入的 App；短按运行所选助手，长按配置它所属的插件。所选插件被移除或不再提供该 App 时，回退到内置助手。以下发送流程对应内置助手。

1. 在 **设置 → 键盘 → 工具栏 → 编辑按钮** 中，为 Kawaii Bar 或 Status Area 添加“AI 助手”。短按打开面板，长按打开助手设置。
2. 配置服务的 HTTPS 地址、模型和 API 密钥。支持 OpenAI Chat Completions、Anthropic Messages 和 OpenAI Responses；地址默认留空，不会回退到内置官方地址。
3. 可以填写基础地址（需要时带 `/v1`）或完整 `/chat/completions`、`/messages`、`/responses` 地址。接口前缀和查询参数会保留，路径随协议切换。
4. 选中文本后打开助手，或直接在面板的“文本”框中输入。键盘继续向这个本地文本框输入，不会把问题直接提交到原应用。
5. 选择用途并点击 **发送 AI**。首次使用需批准 App 能力，首次访问配置中的新域名还需单独允许网络访问；批准后才发送文本与密钥。
6. 返回的文字显示在面板的 **AI 回复** 区域，并在原应用输入框中临时预览；可长按选择、复制回复。此时 **确认上屏** 才出现，点击后提交该回复并关闭助手。也可选择“重新生成”。
7. 修改问题、用途或服务会使旧回复失效，旧回复不能再误上屏。清空、关闭或系统返回会撤销预览并恢复原选中文本；请求失败保留问题和窗口，空文本不发送请求。

旧的 `confirm` 事件在没有有效回复时也会进入 AI 生成流程，不会直接关闭窗口；已有当前问题的有效回复时才执行上屏。

面板没有背景遮罩，拖动标题或空白处可移动；面板与下拉菜单受键盘和屏幕边界限制，空间不足时滚动或向上展开。文本编辑、选字、回复滚动与复制手势不会触发拖动。

每个服务配置分别保存地址、模型、密钥和协议。新增的成语接龙、白话转文言、中译英、火星文等用途与简答、润色、纠错、调整语气同样使用所选服务。

当前尚不提供流式回复、图片输入、多轮对话或工具执行。界面与协议回归使用模拟网络响应，真实 API 可用性及真机手感仍需按设备和服务验证。

## JS 工具与内置翻译

独立的 **JS 工具** 模板用来把翻译等文本 App 绑定成直达按钮。**AI 助手** 按钮打开设置中选用的助手；每个 JS 工具按钮则保存一个明确的插件 ID 与 App ID，点击后直接打开目标，不会在运行时再次要求选择。可以同时添加多个不同 App，默认布局不自动增加按钮。

新版 APK 内置从用户提供的元书脚本适配而来的 **翻译（免密钥）** App。它使用有道公开演示接口 `aidemo.youdao.com`，无需 API 密钥，但公开服务可能限流、变更或停用；内置只表示脚本随 APK 提供，不保证第三方服务长期可用。

1. 打开 **设置 → 键盘 → 工具栏 → 编辑按钮**，从 Kawaii Bar 或 Status Area 的“＋”菜单选择 **JS 工具**，再选 **翻译（免密钥）** 或其他已注册 App。一个插件注册多个 App 时分别列出，条目附带插件名；纯语音识别插件仍从语音入口使用。
2. 保存后，按钮使用所选 App 的名称和稳定身份。短按直接打开该 App，长按进入其插件设置；要添加另一个 App，再添加一次 JS 工具模板并选择目标。目标插件或 App 已不存在时只提示重新配置，不会误开内置助手或列表中的其他项；重新安装相同 ID 与 App 后按钮可重新解析到当前源码。
3. 翻译工具打开时只读取当前选区，不联网，也不自动读取剪贴板。可以在面板继续输入或手动粘贴，选择目标语言后点击 **翻译**，此时才把待翻译文本发送到上方域名。
4. 翻译成功后，**原文** 与只读 **译文** 两个文本框同时留在可视区域，便于直接对照；原应用也会尽量显示临时预览。删去重复说明与成功提示后，底部用短标签紧凑排列 **清空／作原文／再译／替换（或插入）**，确认后才正式提交。目标输入框不接受临时预览时，面板仍保留译文和确认入口。“作原文”可把译文放回原文框开始下一轮；关闭、取消、清空或失败会撤销尚未确认的预览。
5. 文本开头也可使用“英 你好”“日：你好”等带空格或冒号的目标语言前缀。要求分隔符可避免把“英语很好”“中文测试”的首字误删。公开端点当前实测支持简体中文、英语、日语、韩语、法语、德语、俄语和西班牙语方向；繁体中文与意大利语目标返回服务错误，因此不在列表中。

公开接口可能在 HTTP 200 的正文中返回 `411` 频率限制；这不表示刚选的语言不受支持。稍后再试即可，应用不会为绕过限制自动重试或改用其他服务。

首次运行任一工具时，宿主会核对 App 能力；首次访问新的网络主机时还会单独请求批准。配置按钮本身不会绕过这些授权，也不会让一个插件继承另一个插件的权限。同一具体 App 已打开时再次点击其按钮会关闭面板、取消未完成请求并撤销临时预览；点击另一个已绑定 App 会结束旧会话并打开新目标。

要安装其他工具，在 **设置 → 便捷功能 → JS 插件设置 → 导入插件…** 选择适配中州鹅的 `.js` 文件。文本工具需要通过 `foxy.app.register(...)` 注册 App；元书等其他宿主的脚本不能直接通用。“JS 工具”提供已注册 App 的选择入口，不是任意 JavaScript 执行框。

## 导入、覆盖与移除

在插件页选择“导入插件…”，导入自包含的 `.js` 文件，源码上限 **256 KiB**。确认窗口会显示名称、ID、版本、网络主机和设置项等信息，确认后安装。

- 同一个已导入插件 ID 表示覆盖升级，保留已有普通设置与密钥。
- 普通“导入插件…”仍保护内置 ID。要修改内置插件，在它的设置页使用 **导入替换**；所选文件必须声明同一个插件 ID，并保留内置项原有的语音或 App 入口。普通导入插件升级时可以调整 App 列表；已被移除的助手选择会立即回退且不会因稍后重装而自动复活。已有语音插件升级时仍须保留语音能力，避免留下失效的语音首选项。
- 在插件设置选择 **导出源码**，可保存当前实际使用的 `.js`。导出不附带宿主保存的设置、授权或密钥；自行写进脚本的内容会原样导出。
- 明确替换内置插件后，自定义版本持续生效，不要求版本号高于内置版，输入法升级也不会自动切回内置。只有历史同 ID 导入记录、没有主动替换标记时，仍使用内置版本。
- 自定义内置项提供 **恢复内置**，切回当前 APK 的脚本，保留设置、密钥和已导入源码。需要再次启用自定义版本时，重新导入替换。
- 替换源码、恢复内置或移除插件会终止同 ID 的活动 JS App／语音会话，并撤销旧 App 能力和网络授权；重新使用时核对授权。导入确认展示静态主机清单，App 访问配置中的新主机仍需单独批准。修改端点设置不会扩大可访问范围。
- 外部插件可在自己的设置页移除；脚本与注册项移除后，原设置和密钥保留，同 ID 重新导入可继续使用。当前首选语音指向已移除插件时会清空并提示；AI 助手选择失效时回退到内置。

这是一条 **导出 → 修改 → 导入替换** 的本地源码管理流程，不自动从网络检查或下载插件更新。要保留独立的自定义助手，也可以使用不同插件 ID 导入，再在 **AI 按钮使用的助手** 中选中它；不同 ID 的设置和密钥独立保存。详细步骤见 [AI 文本助手](./ai-assistant#选择和修改助手)。

## 网络授权与密钥

语音网络访问必须同时满足 **脚本声明主机 + 用户批准该插件 + HTTPS/WSS**。授权互相独立，可以在对应插件设置页撤销；撤销后新会话与已有连接的后续网络操作都会受阻。

App HTTP 可以使用静态声明主机或用户已配置的 HTTPS 地址主机，但都要逐域名批准。内置助手的 `hosts` 为空，不需要修改 JS 中的白名单。换成未批准的新域名时，首次请求会重新询问；修改路径、模型或端口本身不单独触发域名授权。禁止自动重定向，`Host` / `:authority` 由网络库根据 URL 生成。

密钥由宿主加密保存，脚本只引用字段名，不能读取明文。不要把密钥直接写进脚本源码或普通文本设置项。
完整备份包含导入脚本、普通设置、授权记录和密钥密文，但不包含 Android Keystore 的解密密钥。**换设备、卸载重装或清除应用数据后，必须重新填写密钥**，详见[备份与恢复](/features/backup-restore)。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| 插件导入失败 | 文件大小、语法、插件 ID，以及语音插件的 `voice.asr` 或文本工具的 App 注册；普通 JS 文件不一定符合宿主协议 |
| 文本插件导入后找不到入口 | 在“编辑按钮”中添加“JS 工具”并选定该插件的 App；旧版没有该模板时需要更新 APK |
| 显示主机未授权 | 打开该插件设置，检查当前脚本的主机清单并明确批准；不要只改端点 |
| 鉴权失败 | 密钥是否重填、鉴权模式是否正确、账号是否开通对应模型或资源；腾讯云核对 APPID 与 UIN |
| 点击后无法录音 | 系统录音权限、当前首选引擎、插件配置及页面错误提示 |
| 结束后还在等待 | 单次请求模式需上传整段音频再等待结果，宿主收尾最多等 40 秒；不要立即切换输入框 |
| 长录音或插件异常中止 | 宿主对内存、消息、缓冲与回调时间设有限额，超限会结束会话；缩短录音或修正插件 |
