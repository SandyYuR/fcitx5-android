# 剪贴板同步（内置）

主程序**内置**剪贴板同步能力，与桌面端 / 其他设备的剪贴板互通——无需安装任何插件（Rime-only 版没有插件体系，此功能一直在主 APK 内）。

## 兼容的同步服务

主程序作为客户端，可连接以下开源剪贴板同步服务的任意一个：

| 服务 | 状态 |
|------|------|
| **[SyncClipboard](https://github.com/Jeric-X/SyncClipboard)** | 已验证 |
| **Oneclip** | 协议兼容 |
| **[ClipCascade](https://github.com/Sathvik-Rao/ClipCascade)** | 协议兼容 |

工作方式：在服务端部署任一同步服务（自建 / 公网 / 局域网）→ 在应用内填服务地址、端口、认证信息 → 复制 / 粘贴内容经服务在多端互通。推荐使用 `https://` / `wss://`；明文 HTTP 只应在完全可信的局域网临时使用。

## 应用内剪贴板

无论是否启用外部同步，应用内剪贴板都提供：

- 历史记录、固定（pin）、删除、搜索
- **历史实时搜索**（本版）：进入剪贴板窗口后点搜索按钮，**工具栏中间变成搜索框**，打字即时过滤历史；结果以卡片显示在键盘上方的辅助栏（最多 50 条、单条最多 3 行）；退格修改查询，工具栏最左按钮退出搜索。搜索只在本机历史里匹配（SQL 筛选 + 防抖），**不外发任何数据**；切换输入框、离开键盘或进入悬浮键盘都会结束搜索
- **文本条目分词选择**：对单个文本条目执行 Tokenize，拆成词 / 字符片段后点选、组合发送到输入框
- 快捷磁贴（Quick Settings tile）可真正启动 / 停止同步服务

## 入口

- 设置：**应用主页 → 便捷功能 → 剪贴板**（远端同步设置在同页进入）
- 键盘内：**Kawaii Bar 的剪贴板按钮**（或状态区同名入口）打开剪贴板窗口

## 文本条目分词选择

1. 在剪贴板窗口中打开某个文本条目的操作菜单
2. 选择 **Tokenize**
3. 在分词结果中点选或拖动选择多个 token
4. 点击 **Send** 将选中的片段组合后发送到当前输入框

## 稳定性与隐私（本版持续加固）

- **release 版日志不再写入剪贴板原文**（语音原文同样）；
- 传输按上限**流式读取**、解码前先过滤尺寸；接收过滤缓存化，不逐条重建；
- 前台服务使用 `dataSync` 类型并空闲降频，后台同步不再"不停摆"；前台状态更新幂等，不重复投递通知；
- 网络栈超时 / 取消语义完善，PBKDF2 参数规范；同步状态使用专用存储并在锁内序列化；
- 历史增量全部导入、游标不再跳过；存储路径解码对裸 `%` 与畸形编码健壮；
- 长文本分词设上限，分词任务跟随视图生命周期取消。

## 已知限制

- 后台被系统杀掉时同步会暂停（Android 系统行为）——国产 ROM 请为本应用开启[自启动与后台权限](/troubleshooting/oem-startup)
- Android 10+ 限制后台读取系统剪贴板；作为默认输入法使用时捕获通常更可靠，必要时用同步通知里的「抓取并同步」做一次前台捕获
