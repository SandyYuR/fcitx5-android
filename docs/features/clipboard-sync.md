# 剪贴板同步

fx 在主程序内**内置**了剪贴板同步能力，与桌面端 / 其他设备的剪贴板互通 —— 无需安装额外插件。

::: warning 待补充
本页提供能力概览，详细配置步骤正在撰写中。
:::


剪贴板同步作为 **主程序的一部分** 提供，安装主程序后即可在设置中启用配置

## 兼容的同步服务

主程序作为客户端，可连接以下开源剪贴板同步服务的任意一个：

| 服务 | 状态 |
|------|------|
| **[SyncClipboard](https://github.com/Jeric-X/SyncClipboard)** | 已验证 |
| **[Oneclip](https://github.com/oneclip/oneclip)** | 协议兼容 |
| **[ClipCascade](https://github.com/Sathvik-Rao/ClipCascade)** | 协议兼容 |

工作方式：

- 在服务端部署一个上述任一同步服务（自建 / 公网 / 局域网）
- 在 fx 内填入服务地址、端口、认证信息
- 复制 / 粘贴的内容会经由服务在多端互通

## 应用内增强剪贴板

无论是否启用外部同步，应用内的剪贴板都提供以下能力：

- 历史记录、固定（pin）、删除、搜索
- 条目内文字垂直居中
- **文本条目分词选择**：对剪贴板中的文本条目执行 Tokenize，将内容拆成词 / 字符片段后选择并发送

## 入口

进入 **配置 → 剪贴板** 查看相关开关；同步服务的地址、密钥等也在此页面配置。

## 文本条目分词选择

这个功能只作用于 **单个文本剪贴板条目**，不是剪贴板列表的批量选择。

1. 在剪贴板窗口中打开某个文本条目的操作菜单
2. 选择 **Tokenize**
3. 在分词结果中点选或拖动选择多个 token
4. 点击 **Send** 将选中的片段组合后发送到当前输入框

## 已知限制

- 后台被系统杀掉时同步会暂停（属于 Android 系统行为）
- 国产 ROM 上请为 fx 主程序开启 [OEM 关联启动](/troubleshooting/oem-startup) 以保证后台同步可用
