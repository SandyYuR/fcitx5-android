候选窗（特别是浮动候选窗）提供以下能力。

## 主要能力

- **总是显示候选窗 (Float Candidates)**：即使无候选时也保持候选条可见，避免 UI 跳动
- **滚动候选**：长候选列表横向滚动浏览
- **候选高亮圆角半径**：可配置高亮区域的圆角
- **高亮切换动画**：切换高亮索引时的视觉反馈
- **物理键盘横向候选**：接入物理键盘时可强制使用横向候选栏
- **浮动候选自动跟随**：贴近键盘、避让光标，竖排场景下也保持稳定定位

## 入口

进入 **配置 → 候选窗** 查看相关开关与参数。
