# 输入统计与键盘测试

默认分支 [`fx-rime-only`](https://github.com/SandyYuR/fcitx5-android/tree/fx-rime-only) 已集成输入统计与键盘测试；需使用包含这些改动的构建。界面和设备行为仍需按实际构建验证。

## 开启与查看

进入“设置 → 便捷功能”，在列表最下方打开“输入统计与字词云”，也可搜索“统计”“词云”或“热力”。**输入统计和字词频次记录默认均关闭。** 开启“记录输入统计”后开始积累数据；需要字云、词云时再单独开启“记录字词频次”，并确认本机会保存输入过的字词及频次。

可选择单个方案或全部方案，再查看今天、本周、本月、本年或所有日期。周从星期一开始，日、周、月、年按设备本地日期划分；更换统计页的筛选方案不会改变输入法实际使用的方案。

页面展示累计生涯字数、阶段进度、当前范围计数、速度、字词云、长度分布和按键热力。输入趋势覆盖所选范围的全部记录：今天、本周、本月按日显示，本年按月汇总，所有日期按年汇总；记录跨度很长时合并相邻年份，各柱合计仍保留该范围的完整总量。评级根据统计指标计算，回删率及其评级不代表文字实际正确率。

计数与速度卡片突出数值，单位、指标标签和说明分别排布，便于比较不同指标。按键热力收紧键间距，采用不随应用或系统字体设置放大的固定字号，尽量在普通屏幕直接展示完整键位。键面名称与占比分层显示，百分比保留完整文字；非零且不足 0.1% 的占比显示为 `<0.1%`。

完整键位能放下时，不显示滑动提示；只有窄屏或自定义键位确实超出可用宽度，才允许横向滚动并显示“左右滑动查看完整键位”。固定字号仅用于键面热力图，页面其他文字和按键频次条形图仍跟随正常字体设置。分享图片会适当扩宽，极窄自定义键仍放不下时改用完整的按键频次条形图。

字云、词云和混合词云按频次调整字号，高频前六项加粗，使用主色系渐变和椭圆螺旋排布。字号和颜色帮助区分常用字词；画布呈现的是高频条目，不是全部已保存词频的列表。

## 统计口径

| 指标 | 记录方式 |
| --- | --- |
| 字数与上屏次数 | 只计原应用已接受、整条完全由汉字组成的 Rime 上屏；一次提交计一次上屏，汉字按 Unicode 码点计数 |
| 中英、数字、标点混合提交 | 整条不计入汉字数或词频；不会从中截取一段当作纯汉字提交 |
| 键数与回删率 | 键数来自真实输入路径准许的 Rime 按下事件；删除键次数除以键数得到回删率 |
| 码长 | 上屏前原始编码长度加上触发上屏的一键；字词长度和码长分布均按每次有效提交累积 |
| 平均速度 | 累积至少一秒且含汉字提交的有效输入段，以这些段的总字数除以总时长 |
| 最高速度 | 向前累计完整输入段，达到至少十秒后计算；键／秒和码／字来自同一个最高字速窗口 |
| 按键热力 | 记录真实软键按压的键面名称，独立于 Rime 键数；宏只取显示名称，不读取展开内容 |

是否还有未完成编码，以每次操作后的组合状态判断。没有未完成编码时，两次按键间隔超过五秒会开始新输入段；首键后仍在组词，或顶功等自动上屏后已开始下一编码时，停顿保留在该段内。隐藏键盘、结束或切换编辑器会结束当前速度段；方案或本地日期变化也会切段，避免把前一日期的组合时长记到下一日期。最高速度采用完整输入段的累计时长，并非严格截取墙钟上的连续十秒。

词云记录两到十二字的完整提交及单字频次，不使用联网分词。每次最多提取前六十四个单字；每个日期、方案最多保存五百一十二种字词和一百二十八个热力标签。词表满后淘汰较低频条目，因此长时间、大词汇量的词云不是无损词频档案。

## 隐私与数据管理

密码、可见密码、网页密码、数字 PIN、要求不作个性化学习的隐私输入，以及无明确文本输入类型的窗口不记录。首次解锁前、输入法内部的 AI 编辑和剪贴板搜索也不采集。直接插入或粘贴的内容不会被当作这一真实 Rime 输入路径的汉字提交。

记录仅写入本机私有 `noBackup` 存储，不上传，不写入 Rime 用户目录或用户词库。**统计不包含在应用整包备份内**；使用统计页菜单的“备份统计”单独导出 JSON，换设备或卸载前保存到应用目录之外。

“恢复统计备份”只支持本应用导出的统计 JSON，最多 32 MiB。恢复会替换全部统计数据，保持当前记录开关，并先保留一份本机导入前备份；格式无效时拒绝替换。它不会累加同一份数据，也不会恢复或修改 Rime 词库。

| 菜单操作 | 影响 |
| --- | --- |
| 清除所选范围 | 清除当前方案筛选和日期范围内的记录，累计生涯字数保留；选择全部方案时作用于全部方案 |
| 清除最高速度 | 只清当前筛选范围的峰值及其速度窗口，不清普通计数和有效输入时长 |
| 清除全部数据 | 删除所有方案、所有日期、词频、热力布局、累计生涯记录、本机导入前备份及其临时文件、统计分享缓存，并关闭统计和词频记录 |
| 分享 | 可分享文字报告，或勾选概览、速度、三种词云、词长、码长、键盘热力与生涯卡中的所需模块生成一张长图；是否发送及发给谁由用户选择 |

统计采用异步批量保存。关闭，或没有待保存数据与待结束输入段时，不设置周期唤醒；有待保存数据时按固定期限写入。开启统计仍会增加本地计数、编码扫描与存储工作，不能理解为零开销。

关闭、清除或恢复操作会隔开前后的记录代次，旧输入回调不能在操作结束后补写回来；关闭记录时仍能清除数据。进行中的分享也核对快照的记录代次，代次变化后取消旧快照分享，避免重新生成已清除内容。统计附属队列溢出只影响可选统计，真实输入事件仍按原顺序交付；页面会明确显示未记录事件数，不据此推算精确按键或性能。

## 键盘测试

普通设置页工具栏提供“键盘测试”图标，可打开临时输入面板，比较文本、数字、密码和 PIN 输入形态。四个标签通常等宽排成一行，超大字号或宽度不足时等宽排成两行两列。浮动或透明辅助窗口不额外加入该入口。

| 类型 | Android 输入类型 |
| --- | --- |
| 文本 | `TYPE_CLASS_TEXT` |
| 数字 | `TYPE_CLASS_NUMBER` |
| 密码 | 文本类加 `TYPE_TEXT_VARIATION_PASSWORD` |
| PIN | **数字类加 `TYPE_NUMBER_VARIATION_PASSWORD`**，使输入法按数字密码处理 |

密码与 PIN 使用掩码显示，并标记不作个性化学习。涉及密码类型的切换会清空旧内容，避免密码重新出现在普通文本框中。面板关闭或离开承载页面后清空内容，重开创建新输入框，不恢复草稿；系统支持时同时关闭自动填充与内容捕获。

密码、PIN 和禁止个性化学习的输入框也会隔开 Rime 会话。在文本框按 Shift 切成英文，经过密码框再回到文本框时，会由 Rime 初始化一个普通新会话；方案有 `ascii_mode` 的 `reset: 0` 时回到中文，没有 reset 时由引擎的已保存值或初始值决定。“同应用普通输入框可复用”要求前后均未经过敏感边界，见[方案与开关](/features/rime-enhancements#方案与开关)。

不保存测试草稿不等于关闭正常输入的学习和统计。普通文本测试仍是真实输入框，遵循当前方案的学习设置；开启统计后，其中符合口径的 Rime 汉字提交可能纳入统计。密码和 PIN 测试始终排除。这个面板方便检查键盘形态，不能替代不同应用、系统导航和真实敏感编辑器的设备回归。

实现与数据边界见[正确性约束](/maintainer/implementation/correctness-contracts#输入统计与键盘测试)。
