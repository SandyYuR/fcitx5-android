# Kawaii Bar 增强

Kawaii Bar 是位于键盘上方的功能状态栏：左侧状态区、中间一排功能按钮、右侧控制按钮，工具栏下方那条候选栏也在其中。

## 工具栏大小（本版新增）

**应用主页 → 键盘 → 工具栏 → 工具栏大小**，默认 100%，可调 **80%–200%**（步进 10%）：

- **栏高与图标一起缩放**：调大后工具栏整体变高、按钮图标随之变大；
- **横向占用宽度不变**：放大只吃图标留白——每个按钮占位 44dp 恒定，200% 时图标约 40dp、留白约 2dp，100% 时图标 24dp、留白 10dp。调到 200% 也**不会**让中间按钮变少或退回横向滚动；
- **候选字号与候选格宽不跟随**：它们只受字体设定的候选字号（`cand_font`）与候选栏自身设置影响。想让候选字变大：**先把工具栏调高**（给候选行腾出高度），再调候选字号——候选文字的高度自动缩放只会缩小、不会放大。

## 主要能力

- **横向滚动**：按钮多时支持横向滚动浏览
- **按钮均布**：默认均匀分布；宽度不足时改为滚动。中央按钮行改为**确定性布局**——每次布局都按当前宽度重算，开关悬浮键盘、单手键盘或进出扩展窗口后中间按钮整排消失的问题已修复
- **语言切换按钮**：**短按**切换子模式/状态，**长按打开系统输入法选择器**（与键盘上的语言键分工不同，见 [LanguageKey](/features/keys/language-key)）
- **激活状态颜色指示**：使用图标颜色标识按钮的激活状态
- **亮 / 暗主题一键切换**与**一键恢复 Monet 默认配色映射**（状态区按钮动作）
- **自定义图标归一**：导入的自定义图标（SVG / 大尺寸 PNG）统一按标准图标尺寸（24dp）显示，不再把按钮撑宽、左右留出空隙

## 按钮自定义

- 按钮的排列与增删在**设置页的顶栏按钮面板**中拖拽编辑，结果持久化；
- ⚠️ 旧版"**长按状态区按钮**进入的浮动拖动编辑面板"**已在本版移除**——别再按旧教程从状态区长按进入；
- 删除自定义宏按钮后，其余按钮不再执行旧宏；InputView 销毁时清理回调，无泄漏。

## 密码框中的工具栏

- 开启「**输入密码时在工具栏上显示数字行**」后，字母类密码框显示可点击的数字行（数字按键用主题普通按键文字颜色，字体跟随按键字体设置，不参与工具栏高度内的文字缩放）；
- 关闭后密码框隐藏普通工具栏按钮及其点击区域，只保留最右侧的收起键盘按钮；纯数字密码框已用数字键盘，不重复显示。

## 与 Rime 的联动

- 状态区支持通用多选下拉，可直接切换 Rime 方案——见 [Rime 引擎（内置）](/features/rime-enhancements)；
- 工具栏上的「方案选单」按钮与长按语言键是同一入口。
