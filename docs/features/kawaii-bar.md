# Kawaii Bar 增强

:::

Kawaii Bar 是位于键盘上方的功能状态栏，提供以下能力。

## 主要能力

- **横向滚动**：按钮多时支持横向滚动浏览
- **按钮均布**：默认偏好均匀分布；宽度小于 32dp 时改为滚动
- **语言切换按钮**：直接在 Kawaii Bar 上切换输入法
- **激活状态颜色指示**：使用图标颜色标识按钮的激活状态
- **on-the-fly 按钮定制**：无需进入设置即可临时调整 Kawaii Bar
- **拖拽自定义编辑器**：通过 FlowLayout 拖拽重新排列按钮

## 与 Rime 的联动

Kawaii Bar 的状态区支持通用多选下拉，常见用法是直接切换 Rime 方案 —— 见 [Rime 集成增强](/features/rime-enhancements)。
