# 分屏键盘

::: warning 待补充
本页内容正在撰写修订中。
:::

横屏场景下的分屏键盘，两侧分别放置一半按键，便于双手握持设备时输入。

## 启用与配置

- 触发条件：横屏布局（可配置为自动 / 手动）
- 自动分屏阈值（自适应屏幕宽度）
- 校准 UI：可视化校准分屏中心位置
- 横屏布局参数选项：触发分屏时使用专属布局参数

## 智能默认

fx 提供智能默认值，多数设备无需手动校准即可获得合理体验。
