# 调整模式

::: warning 待补充
本页内容正在撰写修订中。
:::

调整模式（Adjust Mode）是一个临时可视化状态，允许你直接拖动键盘边缘、移动手柄修改键盘的尺寸与位置。

## 进入方式

- 浮动键盘下：点击键盘上方的"调整"按钮
- 也可从 Kawaii Bar 入口进入

## 可调整项

- 整体宽度、高度
- 在屏幕中的 X / Y 坐标
- 内部边距（与主题 / 布局编辑器配合）

## 保存与恢复

- 退出调整模式时即时保存
- 横屏/竖屏独立保存
- 可在配置中恢复默认值
