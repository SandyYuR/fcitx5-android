# 调整模式

调整模式（Adjust Mode）是一个临时可视化状态，允许你直接拖动键盘边缘、移动手柄修改键盘的尺寸与位置。

![调整模式](images/adjust-mode.jpg)

## 进入方式

- 正常非浮动键盘下：**长按工具栏（Kawaii Bar）上的「浮动键盘」按钮**；调整模式中再点一次该按钮即退出调整模式。

## 调整方法

- 拖动上方手柄调整键盘高度（当前屏幕状态）
- 拖动左右侧手柄调整左右边距（当前屏幕状态）
- 拖动中间十字箭头手柄调整底部边距（当前屏幕状态）

## 保存与恢复

- 点击 `默认` 恢复程序默认尺寸设定（当前屏幕状态）
- 点击 `确认` 保存调整结果并退出调整模式
- 横屏/竖屏独立保存

::: tip 与键盘高度设置的关系
调整模式改写的就是全局设置本身：拖动结果写入 **键盘 → 虚拟键盘** 的「键盘高度」「键盘两侧边距」「键盘底部边距」中当前屏幕方向（竖屏或横屏）的那一项，不是另存一份叠加值。若当前布局文件为自己设置了键盘高度，调整高度时改写的是该布局的高度覆盖值。**高级** 设置里的「键盘高度百分比」只决定百分比按什么尺寸计算（默认按真实屏幕尺寸），调整模式不会改动它。
:::
