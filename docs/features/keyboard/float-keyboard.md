fx 提供完整的浮动键盘形态，与上游默认的贴底布局并列。

## 启用方式

- 通过 Kawaii Bar 上的 **浮动键盘** 切换按钮一键切换
- 或在 **配置 → 全局选项** 中找到相关开关

## 主要能力

- **任意位置摆放**：拖动键盘顶部的移动手柄
- **调整尺寸**：进入 **调整模式** 后可自由改变宽高
- **横竖屏独立记忆**：分别保存横屏与竖屏的位置/尺寸
- **与候选窗联动**：浮动键盘下候选窗位置会随键盘智能跟随
