# 分体、浮动与单手键盘

三种键盘形态集中在 **应用主页 → 键盘 → 分体、浮动与单手键盘**。本页列出该页的全部开关与默认值，以及三种形态之间的关系；各形态的操作细节见对应页面。

## 设置一览

| 分组 | 设置项 | 默认 | 说明 |
| --- | --- | --- | --- |
| 分体键盘 | 自动分体键盘 | 开 | 键盘实际宽度达到分体阈值时分体；关闭后始终不分体 |
| 分体键盘 | 分体键盘时采用横屏布局参数 | 关 | 仅在“自动分体键盘”开启时可用 |
| 分体键盘 | 分体时复制中间字母键 | 开 | 同上 |
| 分体键盘 | 强制左右两半在中缝处对齐 | 开 | 同上；两种对齐策略见[分体键盘](./split-keyboard) |
| 分体键盘 | 分体键盘校准 | — | 打开校准页调整分体阈值（首次安装按设备类型写入，识别不到时 470 dp）与中缝间隙（默认 20%）；同样仅在“自动分体键盘”开启时可用 |
| 浮动键盘 | 启用浮动键盘 | 关 | 与“启用单手键盘”互斥 |
| 浮动键盘 | 横屏时自动使用浮动键盘 | 关 | 转横屏临时切到浮动，转回竖屏恢复；不改写“启用浮动键盘” |
| 浮动键盘 | 自动隐藏移动把手 | 关 | 浮动键盘闲置 3 秒后隐藏移动把手，双击尺寸调节把手重新显示 |
| 单手键盘 | 启用单手键盘 | 关 | 与“启用浮动键盘”互斥 |
| 单手键盘 | 靠右显示 | 开 | 仅在单手键盘开启时可用；关闭后显示在左侧 |

工具栏或状态区还可放置“浮动键盘”“单手键盘”“分体键盘”按钮，作用与上表开关相同；“分体键盘”按钮默认不预置，切换的是“自动分体键盘”。从按钮改动后，再进入设置页时开关按实际状态显示。

## 形态之间的关系

- **浮动与单手互斥**：开启其一会关闭另一个，设置页与工具栏按钮都遵守这一规则。
- **横屏自动浮动只在两者都未开启时介入**：已手动开启浮动或单手键盘、或正处于[调整模式](./adjust-mode)时不切换；它只改当次显示形态，转回竖屏时只收回由它自动打开的浮动，你手动开启的浮动保持不变。
- **分体按键盘实际宽度判定**：是否分体取决于当前键盘宽度与分体阈值，而不是单独的开关组合；浮动或单手使键盘变窄时，宽度达不到阈值就按普通排列显示。
- **单手的左右按横竖屏分别记忆**：设置页的“靠右显示”对应竖屏；在键盘上切换左右时，按当前屏幕方向分别保存。
- 关闭浮动或单手后恢复常规停靠；浮动键盘的位置与尺寸、单手键盘的宽度都按横竖屏分别保存。
