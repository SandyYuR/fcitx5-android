# 中州韵引擎变体

除了随主 APK 打包的内置引擎，中州鹅可以加载实现 `org.rime.plugin.MANIFEST` 协议的引擎提供 APK，或用户导入的自包含 `.so`。日常使用不需要它；方案、部署与同步等通用设置见 [中州韵引擎设置](./rime-enhancements)。

## 入口与列表

入口位于「设置首页 → 中州韵引擎 → 中州韵引擎设置 → 引擎变体」。列表依次显示内置引擎、实现 `org.rime.plugin.MANIFEST` 的已安装提供 APK，以及用户导入的自包含 `.so`。内置引擎继续随主 APK 打包，并承担 Direct Boot 和最终故障回退。

内置条目的系列与源码提交读取本 APK 打包的 SDK 元数据，与当前选中的外部引擎分开显示。开发 SDK 显示基线提交和工作树内容标识；旧 SDK 缺少系列或元数据不可读时明确显示未知，不依据外部引擎名称猜测内置来源。

## 切换与工作目录

外部引擎分别绑定已登记的 Rime 工作目录。切换或修改活动引擎的目录会在 owner 线程停止当前引擎槽、销毁会话、加载目标槽并强制完整部署，不再把普通切换实现为输入法进程重启。设置页在这段时间显示不定进度条，输入门控拒绝部署前和部署中的旧按键；成功后恢复当前编辑器绑定。外部引擎使用期间，旧“数据目录管理”的直接切换和方案 ZIP 导入入口会拒绝操作，须回到本页修改引擎绑定。被任一外部引擎或内置回退状态引用的目录也不能重命名或删除，需先解除或迁移引用。删除引擎二进制不删除工作目录与用户数据。

## 部署失败但仍可启动

使用 librime-evo 引擎时，部署任务可能因方案缺少部分辅助资源而报告 failure，但主工作区已经可用。只有 `<user>/build/default.yaml` 是普通文件、引擎能列出方案、当前方案编译出的 `build/<schema>.schema.yaml` 非空，且当前方案主词典的 `build/<dict>.table.bin` 与主 prism 的 `build/<prism>.prism.bin` 都存在且非空时，应用才清除输入门禁并记录“降级部署”。主 prism 按方案声明的 `translator/prism`、`translator/prisms`（可引用 `input_types`）解析；两者都未声明时使用 `build/dictionaries/<dict>/algebra` 的首个分组。显式名称优先限定为 `<dict>.<prism>`。任一条件不满足仍失败关闭。日志和缺失文件不会被改写或补齐，降级也不表示方案完整、词典全部编译或模型已验证，详见 [中州韵引擎设置](./rime-enhancements#部分部署失败时的降级)。

## 启动守卫与故障回退

每次普通进程准备启动外部引擎时，都会在发布或加载外部代码前原子写入一次启动守卫；显式切换和活动绑定变更还会要求完整部署。只有 native 初始化、需要的部署和方案刷新完成后才清除守卫。进程内保留内置槽与有限数量的已授权外部槽：每槽只执行一次 `setup`，切走前先销毁会话并 `finalize`，外部 DSO 不在普通切换中 `dlclose`。目标加载或部署以异常返回时会重新启动仍在内存中的先前槽；若执行外部代码时进程崩溃、操作超时或回退也失败，下一次启动再按持久守卫恢复，最坏回到内置引擎。文件、签名、授权或目录失效同样按该回退链处理。

## 导入 `.so` 的安全检查

文件导入先静态检查 Android ELF，再经用户确认在一次性 Android isolated UID 进程里探测真实 Rime API，最后显示版本、能力、摘要与工作目录供第二次授权。探测进程不继承应用 UID 和已授予权限，只接收只读文件描述符；它会把同一载荷复制到自己创建并封印的不可写 memfd 后加载，不直接执行主应用私有文件，也不运行应用的常规初始化。设备内核或安全策略不支持安全 memfd 与完整封印时会拒绝探测，不改用较弱方式。该探测只验证函数表、必需入口和版本，不能证明某套方案、词典、Lua 或模型可以部署。最终导入的原生代码仍会在输入法主进程执行，因此正式授权依然是完整信任授权。页面因主题、语言或系统配置重建时会取消当前确认并清理自己的实例暂存，用户需要重新选择文件。`.so` 本身没有 Rime 统一的名称、作者或仓库描述；可读信息来自 ELF 及运行时 API，显示名称由用户提供。

## 提供 APK 的授权

提供 APK 的授权还固定签名证书 SHA-256、载荷 SHA-256 和 SONAME。真正启动前，宿主先把载荷复制为应用管理、按授权摘要命名的只读执行快照，再重新查询提供 APK 的证书和协议元数据；复制期间发生更新或任一值变化都会拒绝加载，不会直接从可能被更新替换的提供者路径执行。`org.rime.plugin.MANIFEST` 是本项目兼容的社区提供协议，不是 Rime 上游规范；协议字段与打包示例见[引擎维护流程](/maintainer/engine-update#运行时引擎变体与提供-apk)。

## 能切换引擎但没有中文候选

先核对当前引擎及其绑定的工作目录，再确认方案、Lua、词典和模型来自该引擎分支要求的配套版本。API 探测通过只说明引擎接口可用，不会检查方案内容；普通版万象与 EVO 专用方案也不能仅凭名称相近混用。

重新部署后查看本次部署日志，优先查找最早出现的配置补丁错误、缺失词典或模型提示。修正后应实际输入编码，确认有中文候选且能够上屏；方案列表里有名称或页面显示部署成功，均不能替代这一步。EVO 引擎的降级启动同样只说明当前工作区能出候选，仍需实际输入验证。`librime-evo@06947eed` 曾存在配置编译失败仍报告成功的问题，修复已推送至该仓库的开发分支；已安装引擎不会自动替换，完整原包的问题也不会因此消失，见[2026-11-12 排查记录](/maintainer/changes/2026-11-12-evo-profile-diagnosis)。排查时保留原方案和用户词库，在独立副本中验证。
