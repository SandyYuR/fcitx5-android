# Rime 引擎与中州韵设置

中州鹅直接调用 librime，保留完整 Android 键盘和设置。
原生 Fcitx Core、fcitx5-rime 及 AndroidFrontend 已移除，Rime 无需插件 APK。
APK 不预装中文方案、完整词典或万象模型，见[快速上手](/guide/quick-start)。

## 目录、导入与部署

“输入与候选 → 中州韵设置”提供方案、预编辑、数据目录、导入、部署与同步。
导入完整方案依赖，或将文件放到当前目录并在 `default.custom.yaml` 配置 `schema_list`。
显式重新部署会重建 Rime 环境，重读 Lua、方案列表与开关；以实际候选和开关变化判断结果。
部署期间不接收输入，模型二进制和用户词库不因重部署清空。

用户词典同步会等待实际完成；启动成功不等于同步成功，失败会明确返回错误。同步及备份保存的维护阶段会暂停引擎输入。

状态栏同步入口会显示失败原因，失败不应使输入法进程崩溃。`.temp.userdb` 是引擎恢复流程的临时库；修复后的引擎枚举时跳过这一保留名称，不把它当作普通用户词典，也不通过删除用户文件来绕过错误。此行为需要包含该修复的引擎 SDK，应用侧异常处理与引擎修复分别验证，见[设备问题复核](/maintainer/changes/2026-11-06-device-fixes)。

这个临时库通常由用户词典同步中的快照合并、词库恢复或旧格式升级创建。同步会读取同步目录中已有的 `*.userdb.txt`，也可能包括本机先前生成的快照，因此并非只有多设备同步才会创建临时库。正常完成会关闭并清理；进程被强制结束、数据库打开失败或删除失败时可能残留。它的存在不等于方案损坏，也不能仅凭同步失败日志判断最初是哪次操作留下的。

## 万象方案更新与高级设置

**仅适用于使用万象方案的用户**，入口为“设置 → 数据与备份”的“Rime方案更新”分组，选择“万象更新”。其下方的“自定义更新”可用于其他 Rime 方案。

更新目标直接使用当前 Rime 工作目录。支持 Base / Pro / Lite / Pure、方案正式／预览通道、CNB / GitHub 下载源，以及全量、仅方案、仅词库、仅模型和仅附加词库范围。全量更新包含较大的语言模型；附加词库只在全量、仅词库或仅附加词库时下载，下载后需自行挂接到主词典的 `import_tables`。

下载页与通知显示当前文件的进度。服务器提供可靠总大小时显示百分比、已下载大小和总大小；未知总大小时保留不定进度提示。标题中的“第几项／共几项”与当前文件百分比各自独立，文件下载到 100% 不代表全部安装或部署完成。断网暂停后保留可续传分片，主动取消则清理本次下载缓存。

资源下载返回 HTTP 404 时，首次请求后最多再重试三次；仍然缺失则跳过该资源，其余可用内容照常安装和部署。页面简要列出因 CNB 或 GitHub 仓库资源暂不可用而跳过的组件，不展示 404 堆栈和长链接。后续更新失败、再次打开页面或恢复已完成任务时仍保留跳过清单；没有可部署资源时显示“本次未部署”。其他下载、解压或部署错误仍按原失败与恢复流程处理。

防覆盖规则可编辑，GitHub Token 使用设备密钥加密保存。资源先暂存再应用和部署，保存前复核目标目录；失败通过现有事务恢复文件。用户数据库、同步数据及默认保护的个人配置继续保留。全部文件受到保护时显示“没有需要写入的文件”，不误报已部署；目录读取失败可在本页重新读取。

高级设置支持常用参数、文件分组、补丁／直写与结构化编辑。读取页面不修改已部署文件，缺失配置由“修复部署”显式处理；草稿在“保存并重新部署”时应用，外部修改冲突会阻止覆盖。短语／简码取消关联及自定义新增字段的重载行为见[完整操作](/manual/DIRECT_RIME_USER_GUIDE_zh-CN#万象更新与高级设置)，维护边界见[正确性约束](/maintainer/implementation/correctness-contracts#万象方案更新与配置编辑)。

## 自定义方案更新

入口为“设置 → 数据与备份 → Rime方案更新 → 自定义更新”。任务保存在本机，支持单独执行、勾选批量执行和批量删除。删除任务不会删除已安装资源。

1. 添加任务，填写名称与 HTTP(S) 下载链接，或通过系统文件选择器授权一个本地文件。文件名会随链接自动建议；手动修改后会保留指定名称。
2. 选择解压或直接复制。支持 ZIP、TAR、TAR.GZ、TAR.BZ2、TAR.XZ，并按内容识别压缩格式；链接带下载参数也可使用。单个来源最多512 MiB，整个批次的暂存资源最多2 GiB、2万个文件。
3. 目标为当前 Rime 工作目录，可每行填写一个相对子目录；`.` 表示目录根。来自 GitHub 等仓库的包通常包含一层外壳目录，可勾选“移除压缩包最外层的单一目录”；要保留包内顶层 `lua/` 等目录时取消勾选。
4. 排除规则每行一个正则表达式，匹配包内相对路径及安装后的相对路径。默认跳过自定义补丁、短语和调频文件，按需要编辑；用户词典、同步记录与运行状态始终不能覆盖。
5. 确认目标后执行。下载显示当前资源的已读字节、总大小与百分比；未知大小显示不定进度。全部任务准备成功后统一写入和部署，准备阶段失败不会安装前半批资源，部署失败会恢复原文件。新安装的方案仍可在 Rime 设置中选择。

网络约束暂停会保留可续传数据，主动取消会清理下载缓存；进入部署后需等待完成或恢复。切换工作目录会阻止旧任务写入新目录。万象更新与自定义更新不能同时启动。全部资源被排除时显示0个文件，不执行部署。

功能参考 [LyraIME](https://github.com/Carlson24/LyraIME/tree/e5b2f0101cc35e6ce8b8f2a9667a93d1d5b6979e) 的自定义任务。这里将输出限制为当前引擎拥有的工作目录和相对子目录，系统文件授权用于读取本地来源，不向任意授权目录复制。解压使用应用内已有库，不调用设备的 `tar` 命令；当前不支持 TAR.ZST。维护与验证边界见[正确性约束](/maintainer/implementation/correctness-contracts#自定义方案更新)。

## 编辑器内预编辑

“编辑器内预编辑”可选“不显示”“编码”“候选预览”。“编码”模式中的光标按原始编码定位，显示用的拼音分隔符不会被算成新增编码。转换文字无法唯一对应编码位置时，光标恢复到引擎当前位置；“候选预览”用于显示预计上屏文字，不按预测词的位置改写编码。

## 方案与开关

语言键短按发独立 Shift，长按打开方案列表。状态区的互斥开关按组显示，方案列表不重复列开关。
方案菜单根据引擎的勾选状态标出当前方案，密码或西文输入的直接输入标记不会代替方案名称。
候选注释遵循方案配置；切换语言、方案会短暂显示提示。
中文空格标签为“中州韵（方案名）”，紧凑为“㞢”，ASCII 状态在中文界面显示“英文模式”。

状态区操作的方案开关按已部署 `default.yaml` 的 `switcher/save_options` 列表记忆，切换应用或重启输入引擎后由 Rime 恢复。互斥组选项会同时保存选中与取消选中的值。方案若为开关声明 `reset`，新会话仍优先使用该默认值；未列入记忆列表的开关只影响当前会话。修改记忆列表后需重新部署。

## 候选手势与编码保护

按住候选后上滑可打开选字操作，下滑打开候选菜单。忘记词汇、注释和词频行为取决于方案与引擎支持。快速滑出候选范围会取消本次选择，见[候选指南](/features/candidate-window)。
候选更新期间，旧列表的点击和菜单操作会失效，不会选中新列表的相同序号。横向、展开和浮动候选使用相同的顺序与版本保护；文字相同的刷新保持画面稳定，展开列表仍会更新后续候选。
长按退格删空编码后会保护正文，抬手后再按可继续删正文；长按连删后上滑，在合成中只清编码，非合成时才清空输入框，见[退格键](/features/keys/backspace-key)。

## 引擎来源与更新

引擎使用 `SandyYuR/librime` 的 `zhongzhou` 定制源码，由该仓库独立构建并发布 Android SDK。输入法固定引用经过验证的 SDK 版本及摘要；当前构建不再使用 prebuilder/prebuilt。
版本和定制来源以对应 APK 的源码与元数据为准。插件和依赖固定到明确版本，不随上游自动更新；升级步骤、组件来源和回退见[引擎、插件与依赖更新](/maintainer/engine-update)。方案文件仍按方案自己的说明更新并部署。
此前更新的固定提交、数量与验证保留在[2026-10-21 引擎记录](/maintainer/history/DIRECT_RIME_ENGINE_UPDATE_2026-10-21)。

## 输入与学习

按键、候选操作和会话管理由单一 owner 串行处理；同应用普通编辑器可复用会话，跨应用与敏感输入隔离。
用户词库通过 Rime 学习和同步。多个输入法不要同时打开同一个外部工作库。
实测数据与边界见[历史交付记录](/maintainer/history/DIRECT_RIME_RELEASE_READY_2026-10-21)。
