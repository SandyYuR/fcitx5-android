# SpaceKey 空格键

发送空格；同时承载一组内置的滑动 / 长按行为，本版为它扩充了**可配置划动动作**与**长按重复输入空格**。

## 内置行为

- **左右滑动**：在文本中移动光标（由 **虚拟键盘 → 按键行为 → 划动空格键以移动光标** 开关控制，默认开）
- **上下滑动**：跨行移动光标（发送 `FcitxKey_Up` / `FcitxKey_Down`）
- **长按**：执行 **空格键长按行为** 全局选项（多选一）：轮换输入法、按住说话等，本版新增 **「重复输入空格（按住连续输入）」**——按住即连续输入空格、抬手即停，节奏与退格连删一致，是否震动跟随「长按重复时震动」

## 可配置划动动作（本版新增）

在**键盘布局编辑器**里选中空格键 → 划动事件，可以像其它按键一样配置划动动作并填**划动标签**。规则：

- 与「划动空格键以移动光标」开关**互斥，开关优先**：
  - 开关**开启**（默认）：滑动移动光标，编辑器里配置的划动动作**不生效**（按键编辑页会给出这条提示）；
  - 开关**关闭**：滑动触发你配置的划动动作。**没填划动标签**时，触发方向由 **虚拟键盘 → 按键行为 → 符号划动方向（符号隐藏时）** 决定（默认「自动」= 上下都能触发）；**填了划动标签**时标签显示在空格键下方、方向固定为向下划。空格键的划动方向**不受主题「标点位置」影响**；
- 两者都不成立时（开关关闭且没配划动动作），空格键不参与滑动，按住在空格上移动不会打断长按。

## 字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| `type` | string | ✓ | 固定为 `"SpaceKey"` |
| `swipe` / `swipeLabel` | — |  | 本版起可在布局编辑器中为空格键配置（受上方开关互斥约束） |
| `weight` / `rowHeightPercent` / 颜色字段 | — |  | 与[共通字段](/features/keys/overview#几乎所有按键都通用的字段)相同 |

::: tip 长按行为是全局选项
空格的**长按**行为由全局选项（**虚拟键盘 → 按键行为 → 空格键长按行为**）控制，不在 JSON 中逐键配置；滑动光标与划动动作的取舍则由开关 + 按键配置共同决定。
:::

## Space 标签样式

提供多种 Space 标签风格（**SubModeOnly** 等），由全局配置选择。

## 示例

```json
{ "type": "SpaceKey", "weight": 0.5 }
```
