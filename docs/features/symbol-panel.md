# 符号、表情与颜文字

在键盘中打开符号、表情或颜文字面板，它们使用独立的分组与最近使用记录。面板占用键盘区域，返回后继续使用原键盘。

## 选择面板布局

入口：**设置 → 便捷功能 → 表情和符号 → 符号面板风格**。

| 风格 | 排列 | 适用习惯 |
| --- | --- | --- |
| 左侧分组栏（Foxy 风格） | 左侧选分组，右侧浏览内容 | 希望同时看到较多分组；也是默认风格 |
| 底部栏（Gboard 风格） | 底部选分组，上方浏览内容 | 更习惯在键盘底部切换类别 |

风格只影响面板排列，共用同一份分类数据、最近记录与发送行为；切换不会得到另一套词条。
分组高亮沿用按键几何与主题配色。符号和表情为六列网格，颜文字为单列。条目高度固定，文字超出可用宽高时等比缩小，始终显示在一行内；较长内容不会自动换行或用省略号代替。

## 返回键盘与退格图标

两种风格的面板均使用当前图标主题：返回键盘按钮读取 `toolbar.virtual_keyboard`，退格按钮读取 `keys.backspace`。缺少对应定义时使用默认图标；切换图标主题后面板随之刷新。自定义这两个槽位即可让面板按钮和键盘保持一致，操作见[图标主题](/features/theme/icon-themes)。

## 最近使用与直达入口

当前选中的分类使用主题编辑器“分隔线与选中态”里的“选中项背景”和“选中项文字”。修改为浅色背景时，可在同组中选择深色文字；两种面板风格均使用这对颜色。

选择条目后会更新对应面板的最近记录。可以通过工具栏或布局切换动作分别直达符号、表情和颜文字。
布局 JSON 中历史名称 `Emoticon` 和相应记录键仍用于兼容，显示名称则按当前语言回退。

## 使用自定义数据

三类面板分别支持自定义 JSON 数据。在应用配置目录的 `config/symbol_catalogs/<种类>/<名称>.json` 准备文件，种类分别是 `symbols`、`emoji`、`kaomoji`，再到“表情和符号”中选择对应文件。

```json
{
  "multiLine": false,
  "groups": [
    {
      "names": { "zh": "常用符号", "zh-Hant": "常用符號", "en": "Favorites" },
      "symbols": ["→", "✓", "☆"]
    }
  ]
}
```

`names` 是多语言名称字典；`symbols` 是条目文本数组。`multiLine` 保留旧版兼容数据，当前 App 的列数按面板类别决定；仅修改这个字段不会让文字换行，也不会把符号或表情改成单列。长文本建议放在颜文字类别。
选中文件不存在或解析失败时回退内置数据，先核对文件位置与 JSON 格式。先备份自己的文件，再修改或替换。

输入某个符号时是否上屏、是否经过 Rime 标点转换，还与使用的按键动作和方案有关。屏幕面板风格不改变 Rime 方案。

键盘标点键和长按弹出标签保留布局或预设中的文字；单字符按键由 Rime `punctuator` 决定上屏。旧 Fcitx 标点映射和 `chttrans` 配置入口已经移除，Rime 的标点预设和 OpenCC 转换继续保留；调整方式见[标点与简繁转换](/features/rime-enhancements#标点与简繁转换)。
