# 在线编辑器

「中州鹅」网页编辑器使用用户确认的白鹅矢量图标，可在电脑浏览器中编辑键盘布局、主题和图标（应用内置了 LAN 编辑桥，页面由本 fork 自己的站点提供）：

[打开在线编辑器](https://sandyyur.github.io/f5a-see-me/){target="_blank" rel="noopener"}

本页的层子布局、行设置、宏键类型和预览方向说明对应 2026-11-21 的源码修订。线上站点的可用功能以实际控件为准；对应提交、核对范围与验证结果见[网页编辑器源码对齐记录](/maintainer/changes/2026-11-21-web-editor-parity)。

## 启动方式

在手机上打开：**键盘 → 键盘布局自定义 → 在线编辑器**（开关式入口）。开启后弹窗给出局域网地址和六位配对码；电脑浏览器打开该地址，输入手机上的配对码后连接。同一开关可**停止服务**。

连接后可在电脑上编辑并直接保存到手机。浏览器保存本次连接凭据，无需每次编辑都输入配对码。
停止服务后本次凭据失效；重新启动会生成新的配对码。该配对码与备份文件密码独立。连续输错 5 次配对码需等待 1 分钟再试；服务启动 3 小时后自动停止。
局域网模式下，编辑器页面与静态资源由手机从 GitHub Pages 取回后转给电脑浏览器（页面缓存 10 分钟），因此手机本身需要能访问该站点。
未连接手机时，也可用文件或二维码在两端传递配置。

### 配对时显示 request origin rejected

当前版本已修复配对页来源策略导致浏览器提交 `Origin: null` 而被拒绝的问题。旧版本遇到此提示时，更新应用，重新启动在线编辑器，并从手机弹窗给出的完整地址进入配对页。重新启动后使用新的配对码；保留请求来源检查。

若更新后仍出现，记录浏览器版本、访问地址以及是否经过代理或地址转发，连同应用版本反馈。

## 可编辑内容

- 键盘布局
- Popup 预设
- 主题
- 图标主题
- 符号、Emoji 与颜文字目录

图标主题编辑器包含当前 App 的 `toolbar.ai_assistant` 槽位，可自定义 AI 助手图标；未配置时预览 App 的默认星形图标。App 已识别的其他新槽位是否出现在网页表单，以网页编辑器自身版本为准，仍可在图标主题 JSON 中手动保留。

## 布局预览与按键编辑

PC 窗口变窄、右侧属性窗改为底部面板时，预览保持同一套键盘比例，不会仅拉宽按键。容器宽度、键高、字号与间距使用统一的缩放基准。选中预览按键后可直接使用键盘编辑属性，按 Escape 经未应用修改检查后返回原按键。

预览的「屏幕方向」可选择竖屏、横屏或自动；自动模式在分体预览时采用横屏。方向、分体、Shift 大写与「合成中」均用于查看键面效果，不会改变已应用的布局。网页按输入法的解析规则和设备度量模拟，手机上的方案状态、实际字体与系统缩放仍以应用显示为准。

![网页布局编辑器中的键盘预览](/images/keyboard-editor-preview-20261031.jpg)

普通编辑和 JSON 导出不等待外部二维码或压缩组件。首次进行 QR／ZIP 操作时才加载对应组件；加载失败会提示，可在网络恢复后重新执行该操作。

新建按键或将按键类型改为「空白占位键（PlaceholderKey）」时，主、副文字会清空，并默认勾选「完全透明」。它只占据布局空间；编辑区仍用占位标记方便选中。宽度权重和「此键后分体」断点会保留。已有占位键的自定义文字、透明设置不会被强制清除。

预览中的彩色圆点是编辑提示，不会添加到导出的布局：

- 蓝点：长按动作。
- 绿点：点击宏。
- 实心紫点：向上或向下划动动作。
- 空心紫点：旧版划动动作。

预览工具栏的「显示提示」控制动作圆点和图例，是网页本地的编辑提示。真实键面副标签使用下面的独立设置。布局切换键（LayoutSwitchKey）的主文字使用按键自身或主题指定的文字颜色；设置合成态覆盖不会改变普通预览的主文字颜色。纵向辅助选择栏支持每个按键的行高百分比，打开并保存按键会保留原有比例。

预览工具栏与主题设置区都提供应用的四项副标签设置：

- **副标签存在时移动主字符**：默认开，单个副标签存在时让主文字或图标为其让位；上下两个副标签同时存在时保持主内容居中。
- **副标签显示在侧边**：默认关，开启后副标签按对应方向贴在侧边；划动方向保持原配置。
- **副标签侧边位置**：右侧或左侧，默认右侧；侧边显示关闭时此项置灰。
- **显示按键副标签**：默认开，关闭后隐藏字母标点和划动副标签，不再为它们留位；主文字或图标仍显示。

这四项属于应用的键盘样式偏好，与普通主题 JSON 分开；网页撤销与草稿会保留它们。默认分支已在编辑桥中提供这四个字段（提交 `b50c9dfe`），使用包含该提交的构建即可读取、保存到手机；更早的安装包没有这些字段。未连接手机时仍可在网页本地预览这些设置。「标点位置」仍只控制单个 ASCII 字母的标点副标签，方向划动标签按布局字段显示。

勾选预览工具栏的「合成中」，主键和辅助栏会显示已配置的合成态覆盖：文字、图标和动作提示切换为覆盖内容，按键位置和宽度保持原排列。颜色默认沿用基础键；覆盖中启用「独立按键颜色」时使用覆盖配色。取消勾选恢复普通状态。这个开关只影响预览，不修改布局 JSON，也不会控制手机上的实际合成状态。

辅助选择栏和竖／横屏键盘高度均由所属子布局的普通与分体排列共用。高度存放在该子布局的 `__meta__`，竖屏与横屏分别设置；不要将高度写到分体排列内部，输入法不会从那里读取。辅助栏在完整预览画布内分配宽度，不会缩窄整块键盘。分体预览中，左、右侧栏的百分比按扣除中缝后的宽度计算，主键也采用同一基准。例如辅助栏为 15%、中缝为 20% 时，侧栏占键盘总宽的 12%。

编辑器保留文件中的方案 ID 或名称键，不自动重命名；仅有分体排列的布局也可以选择和编辑。个人布局通过「导入 JSON」载入。

「新建」可创建独立布局、方案子布局或层子布局，并选择复制来源。方案子布局用方案 ID 或显示名；层子布局只需填写「数字」「符号」等名称，网页会保存为 `__layer__:数字` 这样的内部键，下拉框显示「层：数字」。命名为数字层的布局可由输入法自动用于数字输入框，匹配规则见[键盘布局编辑器](/features/editor/layout-editor#层子布局与数字键盘)。

每行旁边的「设置」可统一行高（1..100，留空自动分配）并选择分体断点。编辑分体排列时还可勾选「分体时保持整行连贯」：不插入中缝，也不复制中间键。行首的 `splitRowDisabled` 标记随行保持；拖动、删除首键及属性窗中的移动会保留该行设置，复制单键不会带走整行标记。删除当前子布局的分体排列只移除它的 `__variant__:split`，普通排列、高度和辅助栏继续保留。

完整按键编辑中的显示文本映射支持方案 ID、名称、`default` 和空名称回退，显示文字中的空格会保留。数字键盘键的原始 `sym` 和自定义键面标签也会保留；修改宽度或颜色不会将非预置键码改成 `KP_0`。

`text_editor` 使用专用预览：工具栏下方是光标触控板和文本编辑按钮栏，底栏总高按 App 的 50 dp 显示；配置多行时，各行均分这一高度，按钮宽度按 App 的权重规则分配。点击底部按钮仍可编辑对应按键。空布局显示 App 默认六个按钮作为参考，不会把这些按钮写入 JSON。

文本编辑面板使用主题的普通／辅助按钮颜色和边框设置，不使用普通键盘的行高、间距、合成态覆盖或分体排列，对应预览选项会停用。连接 IME 后按手机返回的尺寸显示；未连接时使用默认设备比例。当前预览采用 App 默认的触控板提示文字和编辑按钮圆角；手机端自定义这两项设置尚未由编辑桥传给网页。

## 符号与颜文字预览

切换到「符号面板」后可编辑分组与条目。颜文字单列显示，符号和 Emoji 按多列排列；`multiLine` 仅保留文件中的旧版兼容标记，不改变当前 App 的列数。

预览可在「侧栏分组」和「底栏分组」之间切换，与应用的两种面板风格对应。此选项只影响预览，不写入目录 JSON；分组、条目、多语言名称及未知兼容字段随目录一起保存，并参与撤销、重做和浏览器草稿恢复。

预览条目保持固定高度，长文字按可用宽高等比缩小并完整显示在一行内，不折行、不使用省略号。颜文字的默认字号为 15 sp，符号为 18 sp，Emoji 为 22 sp；预览变宽后会恢复合适字号。缩放只影响预览，不改导出的文字和目录数据。

## 宏、主题与资源

宏的按键步骤可选择 Fcitx 键名或 Android 整数键码，预置列表提供输入建议；导入的合法自定义键名和 Android 引用会保留。快捷键仍需明确区分修饰键与目标键。切层目标可以输入当前布局的层名或完整布局键；应用动作可填写 `js_app:<插件 ID>/<App ID>` 等稳定标识，保存后需在手机上核对目标是否存在及相关授权。

图片主题按保存的裁剪矩形和旋转角度预览、导出；主题或图标 ZIP 中的相对资源随包保存，重导入后继续使用。网页内置图标预置与当前应用资源按槽位核对。自定义字体和成套主题的字体绑定，以及完整的 Monet 动态色设置，仍在应用内配置；网页预览不能替代这些设置的实机效果。

## 撤销与浏览器草稿

顶部的撤销、重做按钮记录已应用的修改；在文本输入框外也可使用 `Ctrl+Z`、`Ctrl+Y`（或 `Ctrl+Shift+Z`）。主题圆角、间距、边框等配置和图标主题缩略图随文档一同撤销、恢复。

草稿保存在当前浏览器、当前站点下，重新打开页面会恢复；连接 IME 时，读取成功后以 IME 数据为准。背景图片字节保存在浏览器的 IndexedDB 中，单张上限 20 MB，当前文档与撤销历史引用的图片合计上限 64 MB。导入图片后，请等状态显示「浏览器草稿已保存」再关闭页面。空间不足或浏览器禁止存储时，页面会提示失败；请及时导出布局、主题或图标主题文件。

清除站点数据会删除草稿。旧版草稿若只保存了图片路径、未保存图片字节，需要重新导入背景图片。浏览器草稿适合临时恢复，长期保留请导出文件。

## 和手机端互导

在线编辑器可以生成二维码，在手机端对应编辑器中扫码导入；也可以反过来：先在手机端导出二维码，再在在线编辑器中导入继续编辑。

## 安全提示（务必阅读）

::: danger 仅在可信网络中短时开启
该功能会在手机上启动**本地 HTTP 服务**供浏览器编辑，当前版本不适合在不可信网络中使用：

- 仅在可信的个人 Wi-Fi 或个人热点中短时开启（手机仍需能访问 GitHub Pages 才能取回编辑器页面）；
- 不要在公司、学校、酒店、商场等共享网络中开启；
- 用完后回到该入口再次点击，在弹窗中**停止服务**；
- 不要把编辑器 URL 发给他人；
- 只需手机内编辑时，优先使用内置编辑器。
:::

## 本版的加固

- 六位配对码用于建立本次连接，停止服务即失效；网页读写还检查本次会话和请求来源；
- 保存使用临时文件同步后原子替换，替换失败时保留原文件；
- 服务改用**有界线程池**，并发连接数上限 8、请求队列上限 16，拒绝超限连接——修复旧实现无界线程可被局域网内连接耗尽进程资源的问题；
- 请求体上限 4 MB（承载布局 / 主题 JSON 足够，防御异常请求）；
- 修复了局域网无法访问的线程池饥饿回归；
- 编辑器页面由本 fork 的 GitHub Pages（`sandyyur.github.io/f5a-see-me`）提供（包含布局编辑的分叉改进：NumPadKey / MiniSpaceKey 编辑、LayoutSwitchKey 切换目标等）。
