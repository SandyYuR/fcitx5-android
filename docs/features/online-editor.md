# 在线编辑器

提供一个可在电脑浏览器中使用的在线编辑器（应用内置了 LAN 编辑桥，页面由本 fork 自己的站点提供）：

[打开在线编辑器](https://sandyyur.github.io/f5a-see-me/){target="_blank" rel="noopener"}

## 启动方式

在手机上打开：**键盘 → 键盘布局自定义 → 在线编辑器**（开关式入口）。开启后弹窗给出局域网地址，浏览器访问该地址即可编辑；同一开关可**停止服务**。

它适合在更大的屏幕上修改配置，再通过二维码导入到手机端。

## 可编辑内容

- 键盘布局
- Popup 预设
- 主题

## 和手机端互导

在线编辑器可以生成二维码，在手机端对应编辑器中扫码导入；也可以反过来：先在手机端导出二维码，再在在线编辑器中导入继续编辑。

## 安全提示（务必阅读）

::: danger 仅在可信网络中短时开启
该功能会在手机上启动**本地 HTTP 服务**供浏览器编辑，当前版本不适合在不可信网络中使用：

- 仅在可信的个人 Wi-Fi 或离线热点中短时开启；
- 不要在公司、学校、酒店、商场等共享网络中开启；
- 用完后回到该入口再次点击，在弹窗中**停止服务**；
- 不要把编辑器 URL 发给他人；
- 只需手机内编辑时，优先使用内置编辑器。
:::

## 本版的加固

- 服务改用**有界线程池**，并发连接数上限 8、请求队列上限 16，拒绝超限连接——修复旧实现无界线程可被局域网内连接耗尽进程资源的问题；
- 请求体上限 4 MB（承载布局 / 主题 JSON 足够，防御异常请求）；
- 修复了局域网无法访问的线程池饥饿回归；
- 编辑器页面由本 fork 的 GitHub Pages 提供（包含布局编辑的分叉改进：NumPadKey / MiniSpaceKey 编辑、LayoutSwitchKey 切换目标等）。
