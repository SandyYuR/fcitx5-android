# 字体集编辑器（字体设定）

本版沿用 **字体集 (Fontset)** 系统——把"哪些位置用哪个字体、多大字号"配置化，存放于应用外部私有目录的 `fonts/fontset.json`（与字体文件同目录）。设置入口是 **应用主页 → 外观 → 字体设定**。

## 可配置位置

| Key | 用途 | 默认字号 |
|-----|------|---------|
| `font` | 基础字体（AutoScaleTextView 通用默认） | 20 sp |
| `key_main_font` | 按键主标签字体 | 23 sp |
| `key_alt_font` | 按键副标签（swipe 提示）字体 | 10.67 sp |
| `cand_font` | 候选词字体 | 20 sp |
| `comment_font` | 候选注释 / 二级提示文字字体（未设置时依次回退候选字体） | 14 sp |
| `popup_key_font` | Popup 弹窗按键字体 | 18 sp |
| `preedit_font` | 预编辑文本字体 | 18 sp |

## 字号与字体分开调

- **改字号**：点每行右侧的当前值（形如 `23 sp`）或后面的齿轮图标，打开滑杆——范围 **8–72 sp**，可一键「重置」回默认；
- 点行标题或下面的预览行打开的是**字体选择**：可勾选多个字体，**排在前面的找不到字形时依次回退到后面的**，最后回退系统字体；长按拖拽可调整优先顺序。多字体回退需要 Android 10 及以上，更早的系统只使用排在第一位的字体；
- 字体文件放在应用外部私有目录的 `fonts/` 子目录，支持 `.ttf`、`.otf`、`.ttc` 与 `.otc`。

## 保存后立即生效（本版）

写完点右上角**保存**，**当前已打开的那套键盘会立刻换上新字号与新字体**——键帽文字、候选栏、展开的候选面板、浮动候选窗、预编辑行、弹出按键气泡都会跟着变。**不必强杀输入法重开，也不必切走再切回**（内部改用单调递增的字体数据版本号，任何一侧都能自行判断是否需要刷新）。

有两处「看起来没换过来」属于**正常现象**：

- **候选字被候选行高度卡住**：候选文字的高度自动缩放**只会缩小、不会放大**——想让候选字真正变大，先把[工具栏调高](/features/kawaii-bar#工具栏大小-本版新增)，再调候选字号；
- **长按弹出气泡**里的字符是自适应缩放的，字号变化时气泡本身也跟着变大变小，观感变化不如候选栏明显。

::: info 从键盘打开字体设定
字体设定只有一份配置，没有可切换的多套字体集。可在 MacroKey 的应用动作或工具栏按钮中选「字体设定」（`edit_fontset`），从键盘直接打开本编辑器；见 [MacroKey 编辑器](/features/editor/macrokey-editor)。
:::
