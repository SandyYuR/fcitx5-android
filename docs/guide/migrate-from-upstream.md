# 迁移到中州鹅

## 本仓库旧 Fcitx 版

当前包名仍为 `org.fcitx.fcitx5.android.fx.rime`。先在旧应用导出完整用户数据，
确认备份保存到应用目录以外；同签名并满足版本条件时可覆盖安装。
升级后检查 Rime 方案、用户词库、布局、主题、剪贴板及外部目录权限。

## 旧直连测试包

`io.github.sandyyur.rime.direct` 与当前主包是两个应用。
先在测试包导出完整备份，在新包恢复并检查数据，确认后再卸载测试包。
两包不能直接覆盖升级，私有目录也不会自动迁移。

## 上游、fxliang 或其他 Rime 输入法

先导出旧数据，再尝试导入。若完整应用备份不受支持，可迁移 Rime 用户文件以及分别导出的布局和主题。
保留 `*.custom.yaml`、用户词库、同步记录和方案依赖；不要将其他引擎的配置当作直连版功能。

复制工作库前强行停止所有使用该目录的输入法；不要复制仍在写入的数据库，也不要长期共用工作目录。
新目录准备好后部署并测试，以新候选和已学词是否出现为准。

## 回退

保留升级前备份和旧安装包。Android 可能阻止版本降级，换签名或卸载还会影响数据。
按[用户手册的备份与迁移说明](/manual/DIRECT_RIME_USER_GUIDE_zh-CN#备份、迁移与升级)操作。
