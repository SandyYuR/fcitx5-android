# 快速上手

## 第零步：先备份、再选择数据目录

旧版升级或测试包迁移前导出完整备份。不要让多个仍在运行的输入法共用同一 Rime 工作目录。
打开“输入与候选 → 中州韵设置”，确认当前用户数据目录。

## 第一步：导入或放入 Rime 方案

可以在中州韵设置导入 ZIP；也可手动将方案、词典、Lua 及模型等完整依赖放入当前目录。
只放一个 `.schema.yaml` 通常不足以运行复杂方案。

在 `default.custom.yaml` 指定方案：

```yaml
patch:
  schema_list:
    - schema: your_schema
```

将 `your_schema` 替换为方案的实际 `schema_id`，回到中州韵设置执行部署。
等待“正在部署”消失后输入。修改 YAML 或 Lua 后重新部署；以新候选、方案和开关是否生效判断结果。

## 第二步：万象 base 示例

从[万象官方仓库](https://github.com/amzxyz/rime-wanxiang)按其说明安装 base 全拼、词典、Lua 与模型。
本项目历史验证使用 v18.1.3 base + LTS，开启上下文调频、简码和小字集；
这不意味着必须使用双拼。个性化 `*.custom.yaml`、用户词库与排序记录在升级前备份。

## 第三步：切换语言与方案

语言键短按发送独立 Shift，中英文行为由方案的 `ascii_composer` 决定；长按打开 Rime 方案选单。
展开状态区管理方案开关，互斥选项按组选择。切换语言或方案时编码区会短暂显示提示。

中文界面的空格标签为“中州韵（方案名）”，紧凑标记“㞢”；英文状态显示“英文模式”。
候选注释由方案决定，应用显示 Rime 给出的内容。

## 第四步：调整键盘与主题

Rime 方案决定编码和词典；键盘布局决定屏幕键位。布局、分体、单手和浮动模式在键盘设置中调整。
外观页可编辑主题、字体、图标和设置页配色，详见[设置界面外观](/features/theme/settings-appearance)。

完整操作见[用户手册](/manual/DIRECT_RIME_USER_GUIDE_zh-CN)，问题排查见[常见问题](/troubleshooting/faq)。
