# 快速上手

完成 [安装](/guide/installation) 后，按以下步骤在 5 分钟内开始输入。

## 第一步：进入主程序

打开 **Fcitx5** 应用。首次启动时会引导你完成基础设置：

1. 启用输入法（跳转到系统设置）
2. 设为默认输入法
3. 提示授予必要权限

如果你跳过了引导，可随时通过 **首页 → 顶部状态条** 回到对应步骤。

## 第二步：选择输入方案

打开 **配置 → 全局选项 → 输入法**，可看到当前启用的输入方案列表。

### 默认包含

- **English (US)** —— 英文键盘
- **Pinyin / Rime** —— 中文（取决于你安装的插件）

### 添加方案

点击右上角 **+** 按钮，从列表中选择想要启用的输入法（拼音、双拼、五笔、Rime 方案等），点击勾选即可加入。

::: tip 没有看到拼音/Rime？
请确认你已安装对应的 **chinese-addons** 或 **rime** 插件 APK。如果已安装但列表中仍看不到，请检查 [OEM 关联启动](/troubleshooting/oem-startup) 设置。
:::

## 第三步：基本输入操作

在任意输入场景下调出 Fcitx5 键盘后：

| 操作 | 行为 |
|------|------|
| **空格** 长按 | 执行已配置的空格长按行为（默认可在设置中调整） |
| **?123 / ABC** | 切换文本键盘布局 |
| **回车** 长按 | 显示 Emoji 菜单 |
| **删除键** 左右滑动 | 选择并删除一段文本 |
| **空格** 左右滑动 | 移动光标 |
| **候选词** 长按 | 删除该词的用户记录（取决于方案） |

## 第四步：常用功能开关

进入 **配置** 页面，几个最常用的开关：

- **主题**：内置多套配色，亦可自定义背景图与按键颜色
- **候选栏样式**：横向 / Kawaii 等
- **键盘高度 / 边距**：适配不同屏幕尺寸
- **单手模式**：左/右手切换，适合大屏设备
- **按键声音 / 震动**：按需开启

## 第五步：准备多套键盘布局

如果你需要在不同场景使用不同键盘，可以创建多个 **TextKeyboard 布局 Profile**。每个 Profile 是一份完整的文本键盘布局文件。

常见用法：

- 日常输入一套布局
- 横屏或平板一套布局
- 符号/编程输入一套布局
- 临时实验布局单独保存

进入 **配置 → 键盘 → 文本键盘布局** 可编辑 Profile；进入 **配置 → 键盘 → 文本键盘布局文件** 可切换当前启用的 Profile。也可以把 **TextKeyboard 布局文件选择** 动作放到 Kawaii Bar，输入时快速切换。
