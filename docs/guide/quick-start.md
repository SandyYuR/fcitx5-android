# 快速上手

完成 [安装](/guide/installation) 后，按以下步骤开始使用。

## 第零步：先放入一个 Rime 方案

::: warning 本版不预置任何输入方案
首次安装并启用后，键盘能正常弹出，但**没有任何可用的输入方案，打不出汉字**——这是预期行为，不是故障。先完成本节即可开始输入。
:::

1. **打开用户数据目录**：打开应用主页 → **输入与候选 → 中州韵设置**，进入用户数据目录（应用外部文件目录下的 `data/rime`）。
2. **放入方案文件**：把方案文件（`*.schema.yaml` 及其依赖的 `*.dict.yaml` 等）复制进去。方案可以从 [rime 官方方案仓库](https://github.com/rime/plum) 或你使用的方案发布处获取。
3. **声明方案**：在同一目录新建或编辑 `default.custom.yaml`，patch `schema_list`：

   ```yaml
   patch:
     schema_list:
       - schema: your_schema
   ```

   `your_schema` 是方案文件里 `schema_id` 的值；`schema_list` 里列了不存在的方案会导致部署失败。
4. **部署**：回到 **中州韵设置** 执行 **部署**，等键盘上的「正在部署」提示消失即可开始输入。
5. **切换方案**：部署成功后，可用方案选单（默认 `Control+grave` 或 `F4`，或 **长按语言键**）切换方案。

::: tip 可选：essay.txt 八股文词频表
想让候选排序更好，可自备 [`essay.txt`](https://github.com/rime/rime-essay)（Rime 官方「八股文」词频表）放进同一个用户数据目录。方案以 `use_preset_vocabulary: true` 声明依赖它时，**缺少这个文件不会导致部署失败**，只是词典会少一批预置短语与词频。
:::

方案引用的 `symbols`（标点）、`key_binder`（按键绑定）等公共预设资源已随 APK 提供，无需自行补装。升级应用不会删除你放在用户数据目录中的方案。

## 第一步：进入主程序

打开 **靓企鹅·中州韵 / Fcitx5.fx.rime** 应用。首次启动会引导你完成基础设置：

1. 启用输入法（跳转到系统设置）
2. 设为默认输入法

首次启动时应用会自动预置 Rime 为默认启用的输入法，并自动安装一批**内置键盘布局、键盘主题和图标主题**（社区贡献，开箱即用）；首次初始化 Fcitx5 与 Rime 可能比平时慢，请不要反复结束进程。

如果你跳过了向导，可随时通过应用首页顶部的状态条回到对应步骤。设置首页顶部还有**搜索框**，支持中文名、英文别名与拼音搜索设置项（如搜「空格 长按」）。

## 第二步：基本输入操作

在任意输入场景下调出键盘后：

| 操作 | 行为 |
|------|------|
| **语言键** 短按 | 向 Rime 发送一次 Shift，由方案的 `ascii_composer`/`switch_key` 规则切换中英文 |
| **语言键** 长按 | 弹出 Rime 方案选单，点选即切换方案 |
| **工具栏语言按钮** 长按 | 打开系统输入法选择器（切换到其他 Android 输入法用这个） |
| **空格** 左右滑动 | 移动光标（在设置中关闭该开关后，可在布局编辑器里为空格配置划动动作） |
| **删除键** 长按连删后上滑 | 一次性清空当前输入框全部文字（含已上屏正文） |
| **候选词** 按住上滑 | 弹出选字窗，把候选按字拆开，滑到哪个字抬手即提交该字 |
| **候选词** 按住下滑 | 呼出该候选的操作菜单（如「忘记词汇」） |
| **候选词** 长按 | 删除该词的用户记录（取决于方案） |

## 第三步：常用设置入口

设置首页按「日常调整 / 按需进入」两层组织，最常用的几处：

- **输入与候选**：中州韵设置、全局选项、候选栏样式、候选窗口
- **键盘**：键盘高度与边距、工具栏大小（80%–200%）、分体 / 浮动 / 单手键盘、键盘布局自定义
- **外观**：主题、图标主题、字体设定
- **便捷功能**：剪贴板（含远端同步）、文本编辑、表情和符号、语音输入
- **数据与备份**：浏览用户数据目录、导出/导入完整用户数据

## 第四步：准备多套键盘布局

如果你需要在不同场景使用不同键盘，可以创建多个 **TextKeyboard 布局 Profile**：

- 日常输入一套布局
- 横屏或平板一套布局（分体键盘还可以按方案单独配一套分体布局）
- 符号/编程输入一套布局

进入 **键盘 → 键盘布局自定义** 可编辑 Profile；布局编辑器支持子模式、层切换、分体布局、空白占位键等，详见 [键盘布局编辑器](/features/editor/layout-editor)。
