# 核心概念

## Rime 方案与键盘布局

Rime 方案决定编码、词典、候选和语言状态；键盘布局决定屏幕键位、显示文字、长按与滑动动作。
换 Rime 方案不等于导入键盘布局，两者分别配置。
布局的子模式可按 Rime 方案覆盖键位，数字和符号层由布局切换。

## 中州韵设置

“输入与候选”内保留一个中州韵设置，管理方案、预编辑、数据目录、部署与同步。
重复的“全局选项”和固定引擎“附加组件”页已移除；旧布局相关快捷方式兼容转入中州韵设置。
候选栏和候选窗口仍各有界面调整入口。

## 部署 / 同步 / 备份：三件不同的事

| 动作 | 作用 |
| --- | --- |
| 部署 | 读取方案、词典和补丁，生成运行数据；显式重新部署会重建运行环境并重读 Lua |
| Rime 同步 | 与同步目录交换用户词典和学习数据 |
| 完整应用备份 | 导出设置、布局、主题、剪贴板等应用数据 |

三者不能互相替代。修改 YAML 或 Lua 后部署；部署期间等待完成再输入。
模型和用户词库不应为了“刷新方案”而清空。升级或迁移前另做完整备份。

## 方案开关与候选注释

状态区二态开关显示当前状态及目标状态；互斥开关按组选择。方案菜单只列方案，不重复列功能开关。
候选注释由方案自己的开关、Lua 和过滤器决定，应用显示 Rime 返回的结果。

## 用户数据与共存

应用私有目录、当前 Rime 工作目录和同步目录分别承担不同用途。
多个输入法独立使用工作目录，通过同步目录交换学习数据；共用工作库会发生锁冲突。
参见[构建版本与数据共存](/guide/builds-and-plugins)。

## 布局 Compose Override

它在输入组合状态改变按键显示和动作，属于键盘前端功能。
它不表示已经实现完整 XKB Compose；按应用 `app_options` 等价也仍在已知维护范围内。
