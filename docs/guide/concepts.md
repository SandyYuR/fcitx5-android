# 核心概念

理解以下几个概念，可以帮助你更顺畅地配置和使用靓企鹅·中州韵。

## Rime 方案（Schema）

Rime 的「方案」决定**输入规则**：编码方式、词典、候选生成和中英文状态。例如朙月拼音、仓颉、五笔、万象拼音等。本版**不预置任何方案**，需要你自己放入方案文件（`*.schema.yaml` + `*.dict.yaml`）并在 `default.custom.yaml` 中 patch `schema_list` 后部署，见 [快速上手](/guide/quick-start)。

部署成功后，**长按语言键**（或默认 `Control+grave` / `F4`）可打开方案选单切换方案。

## 键盘布局（Layout）

键盘布局决定**屏幕上有哪些键、每个键显示什么、点击/滑动/长按后执行什么动作**。它与 Rime 方案是两回事：

- 换 Rime 方案 = 换一套输入规则；
- 换键盘布局 = 换一套键位排布。

同一份布局内部还可以有**子模式**（按 Rime 方案分别定制键位）、**层**（数字层、符号层）与 `LayoutSwitchKey`。布局通过 **键盘 → 键盘布局自定义** 编辑，详见 [键盘布局编辑器](/features/editor/layout-editor)。

## 中州韵设置 与 全局选项

位于 **输入与候选** 下，由引擎的配置描述树自动生成：

- **中州韵设置**：Rime 引擎配置——启用的方案、用户数据目录、**部署**、**同步**等动作；若某项目没有中文描述，界面会直接显示引擎内部键名（上游限制）；
- **全局选项**：Fcitx 全局行为（触发键、共享输入状态等）。

## 部署 / 同步 / 备份：三件不同的事

| 动作 | 作用 | 何时用 |
|------|------|--------|
| **部署** | 读取 YAML 与词典源文件，生成本机运行数据 | 改了配置、加了方案/词典之后 |
| **同步** | Rime 用户数据与同步目录交换（用户词典迁移/备份） | 需要保证用户词典落盘时主动执行 |
| **导出用户数据** | 应用层整包备份（设置、数据库、外部文件 ZIP） | 升级、迁移、大改配置之前 |

三者不能互相替代。为避免退出输入法时卡顿，本版不会在每次退出时强制执行完整 Rime 同步；重要数据请主动同步并定期导出完整备份。

**部署期间**键盘的预编辑/候选区会显示「正在部署」，此间按下的字母会被丢弃（不会进编码，也不会直接上屏）。只有配置真的变了才会触发部署——无关的目录活动（词典落盘、清理临时文件等）不会像旧版那样引发全量部署。

## Addon（附加组件）

Fcitx5 框架的扩展模块。上游以独立 APK 分发；**本版将 Rime 直接编入主 APK，不再使用插件 APK**，原先的插件发现与签名白名单框架已删除。「高级 → 附加组件」页可查看本 APK 内保留的 Fcitx 组件。

## 候选栏与候选窗

- **候选栏**（工具栏里的横条）与**独立候选窗**是两个作用域：前者的高亮圆角/边距在 **外观 → 主题 → 配置** 里，后者在 **输入与候选 → 候选** 里，互不影响；
- 候选栏新增紧凑 / 标准 / 宽松预设；候选项支持按住上滑选字、按住下滑呼出菜单。

## 符号 / 表情 / 颜文字面板

Foxy 风格的 catalog 驱动实现：左侧分组栏 + 右侧网格，约 6900 条内置条目（符号 4773、表情 1926、颜文字 999）；三类数据都可换成自定义 JSON（导入前先校验格式，解析失败自动回退内置）。见 [用户指南 §5.8–5.9](/manual/RIME_ONLY_USER_GUIDE_zh-CN)。

## 用户数据

包括 Rime 方案与用户词典、词频、布局/主题/宏配置、剪贴板历史等，存放于应用私有目录；**卸载应用会一并删除**。升级、迁移前请用 **数据与备份 → 导出用户数据** 备份。
