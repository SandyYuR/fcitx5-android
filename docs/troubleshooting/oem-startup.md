# OEM 自启动与后台限制

在 **小米 (MIUI / HyperOS)、华为 (EMUI / HarmonyOS)、OPPO (ColorOS)、vivo (OriginOS / FuntouchOS)、荣耀、realme** 等国产定制 ROM 上，系统默认会对应用的常驻进程、后台活动与跨应用唤起做严格管控。

::: danger 影响
本版引擎内置于主应用，不依赖独立引擎插件 APK；JS 语音插件也由应用承载。输入法服务、剪贴板同步、更新检查等仍可能受系统后台策略限制，表现为：

- 键盘首次调起明显变慢，或偶发需要重试；
- 剪贴板同步时断时续、后台捕获失败；
- 通知被折叠或丢失。
:::

## 解决方法

### 重启后首次解锁前无法输入

这一阶段 Android 尚未开放用户的凭据加密存储。应用在已解锁时会自动把当前选中的布局同步为设备保护存储快照，文字密码可读取该快照；快照缺失、密码布局解析失败或没有可用按键时继续回退，最终使用内置 26 键。数字密码使用数字盘，按键直接输入，不依赖中文方案。

只同步当前布局，不会把 Rime 用户词库和日常方案搬到可提前读取的目录。字体、图标和正常方案在首次解锁后的进程重启中恢复。若锁屏显示旧布局，先在已解锁状态打开应用并检查当前布局是否可正常加载；源文件被删除或无效时会清除快照。相关实现有框架回归，真机冷重启体验仍需按具体设备验证。

只有空白占位键的密码布局同样视为不可输入，会继续回退；布局含有正常按键时仍保留其占位与排版。

如果日志出现 `SharedPreferences in credential encrypted storage are not available until after user is unlocked`，这是应用启动时读取了尚未解锁的设置，需要应用修复。反馈时请注明是否为重启后的首次解锁，并按[反馈问题](/troubleshooting/report-issue)提供版本与日志。

### 小米 (MIUI / HyperOS)

1. **设置 → 应用设置 → 应用管理 → 中州鹅（Fcitx5.fx.rime）**
2. **权限管理 → 自启动**：开启
3. **省电策略**：选择「无限制」

### 华为 (EMUI / HarmonyOS)

1. **设置 → 应用和服务 → 应用启动管理**
2. 找到本应用，关闭「自动管理」
3. 在弹出的对话框中勾选「允许自启动」「允许关联启动」「允许后台活动」

### OPPO (ColorOS)

1. **设置 → 电池 → 应用电量管理**
2. 找到本应用，关闭「智能控制后台活动」
3. **设置 → 隐私 → 启动管理**：允许自启动

### vivo (OriginOS / FuntouchOS)

1. **i 管家 → 应用管理 → 自启动管理**：开启本应用
2. **设置 → 电池 → 后台高耗电** 中允许其后台活动

### 一加 / 荣耀 / realme 等

机制大同小异，关键词：**自启动**、**后台活动**、**关联启动**、**省电策略 → 无限制**。

::: tip 同时并存多个输入法版本时
如果同一台设备上还装着上游 / fxliang 版本，对它们做同样的设置即可——各应用相互独立，权限也是各自生效。
:::

## 验证是否生效

1. 设置完成后，**重启手机**（重要）
2. 打开本应用，确认引擎初始化正常
3. 在输入框中调起键盘，观察首次调起速度与剪贴板同步是否稳定

## 仍然不行？

请到 [反馈问题](/troubleshooting/report-issue) 提交 issue，并附上：

- ROM 名称与版本（如 MIUI 14、HarmonyOS 4.0）
- 已为本应用开启了哪些权限
- 是否重启过设备
- 问题发生时的具体场景（首次调起？后台同步？）
