# 中州鹅用户手册（直连 Rime 版）

本手册描述当前维护中的直连版；旧 APK 的差异请结合对应版本说明阅读。应用名 **中州鹅**，包名 **`org.fcitx.fcitx5.android.fx.rime`**。
本版直接使用 Rime 引擎，并提供完整键盘、候选、布局编辑器、主题和设置界面。
Rime 方案决定输入规则与词典；键盘布局决定屏幕按键和手势，两者分别设置。

## 安装与首次输入

1. 从 GitHub Actions 获取主应用，日常使用优先选成功的 `Commit CI` 中的
   **`direct-rime-frontend-arm64-release`**。它是常用 ARM64 手机的完整界面签名 Release。
   Releases 提供“中州鹅”Nightly。`Direct Rime CI` 的
   `direct-rime-frontend-arm64-debug` 是完整界面调试包；
   `direct-rime-arm64-debug` 仅为引擎诊断工具。
2. 安装后，在 Android 系统设置中启用并选择“中州鹅”。Debug 包名为 `org.fcitx.fcitx5.android.fx.rime.debug`，可与 Release 共存；两者数据独立，Debug 也要自行导入并部署方案。
3. 打开应用，进入“中州韵设置”，准备下面所述的 Rime 用户文件并部署。

APK 不内置中文方案、完整词典或万象模型，只包含 Rime 通用标点、符号与按键绑定预设。
初次安装时键盘能弹出但没有中文候选，通常是还没导入方案。
覆盖升级需要同包名、同签名；本地签名包和 CI 包不保证能够互相覆盖。

## 引擎版本与方案更新

APK 内置固定版本的 librime、Lua 运行时和引擎插件；重新启动应用、部署方案或检查更新都不会自动升级这些组件。安装引用新版引擎 SDK 的输入法 APK 后才会使用新引擎。

万象等方案的 YAML、词典、Lua 脚本和模型由方案自己维护，按方案说明更新文件并部署。方案脚本、Lua 运行时与 librime-lua 插件是不同层次，升级其中一项不会自动更新另外两项。升级前保留自定义补丁和用户数据备份。

确切引擎版本可查看对应 APK 源码中的 `native/rime-sdk.lock.json` 和发布说明。维护者构建、依赖升级及回退步骤见[引擎、插件与依赖更新](../maintainer/engine-update.md)。

开发者可在 Windows 本机修改引擎并生成独立 Debug 包，操作见[本地引擎开发](../maintainer/local-engine-development.md)。这类开发包以构建时保存的 `sdk-manifest.json` 源树和摘要为准，不改变日用发行包的版本锁。

## 导入方案与万象

### 从方案 ZIP 导入

进入“导入 Rime 方案”，选择方案 ZIP。压缩包根目录应直接包含 `default.yaml`
或 `default.custom.yaml`，以及方案、词典、Lua 等依赖文件，不能只放一个仓库外层目录。
选择 ZIP 后选择导入到应用目录或可访问的外部目录；未具备外部访问权限时，可改用应用目录。导入完成后按页面提示部署，原目录仍可在数据目录管理中切回。
压缩包上限为 512 MiB。方案 ZIP 与“完整用户数据备份 ZIP”用途不同。

导入页用状态卡片显示读取、检查和导入阶段，实际开始导入时列出目标目录；完成结果留在页面中，错误可展开查看详情。已有的目录选择、权限申请和方案校验仍需完成。

### 手动放置方案

在“中州韵设置”打开当前用户数据目录。默认位于应用外部文件目录的 `data/rime`，
具体以当前数据目录设置为准。将方案及完整依赖放入该目录，在 `default.custom.yaml` 指定方案：

```yaml
patch:
  schema_list:
    - schema: your_schema
```

将 `your_schema` 替换为方案实际的 `schema_id`，然后在中州韵设置执行部署。
修改 YAML、词典或 Lua 后一般需要重新部署。部署期间等待“正在部署”消失后再输入。
重新部署会卸载并重建 Rime 运行环境，重新读取 Lua 模块、方案列表及开关；完成后恢复可用状态。
是否生效应以新方案、开关和实际候选为准，按钮闪烁的时长不能单独证明部署结果。

### 万象 base 配置示例

从 [万象官方仓库](https://github.com/amzxyz/rime-wanxiang)准备 **base / 全拼**版本，
按上游说明安装它依赖的词典、Lua 和语言模型。
需要相应功能时，在所装方案支持的开关中开启“上下文调频”“简码”或选择“小字集”；开关名称与模型文件以对应万象版本的说明为准，这些是可选配置示例。
“简码开启”与“使用双拼”是不同的选项，不需要为了开启简码改成双拼。

候选注释由方案自身的开关和过滤器决定。应用显示 Rime 提供的注释，
不额外把候选编码拼在后面。注释不符合预期时先确认正在使用的方案与开关，
再核对 Lua、配置补丁和部署日志。

日常方案升级请遵循万象自己的说明，并保留 `*.custom.yaml`、用户词库和手动排序数据。
本项目的性能测试使用固定官方夹具和新用户库，不能替代个人长期词频库的实机体验。

## 切换语言、方案和功能开关

- 语言键短按发送独立 Shift，中英文切换行为由方案的 `ascii_composer` 决定。
- 长按键盘语言键或使用“Rime 方案选单”切换方案；工具栏语言按钮长按可打开 Android 输入法选择器。
- 展开状态区可操作方案功能开关。二态按钮显示当前状态及目标状态；互斥选项按组显示，点开后选择。
- 切换中英文时编码区短暂显示“英文模式”或“中文模式”；切换方案时显示方案名。
  提示会自动消失，继续打字时让出编码区，切换输入框后不延续旧提示。
- 空格键在中文界面显示“中州韵（方案名）”，其他语言显示“Rime (方案名)”；
  紧凑中文标记为“㞢”。英文状态名称在中文界面显示“英文模式”。

## 设置入口

“输入与候选”内保留一个“中州韵设置”，用于方案、目录、预编辑方式、部署和同步。
候选栏和候选窗口属于界面设置，仍分别提供调整入口。
“编辑器内预编辑”中的“编码”支持按原始编码定位光标，显示分隔符不会被当作编码字符；无法确定对应位置的转换文字会恢复引擎光标。“候选预览”不按预测词位置修改编码。候选更新时，旧候选的点击不会作用于新列表的同一序号。
重复的“全局选项”、固定引擎的“附加组件”列表和旧快捷键隐藏开关已移除。

设置首页的搜索框支持名称、别名及拼音。可搜索“主题”“布局”“字体”“候选”“备份”等，
跳转到对应设置页。开发者页中的引擎重启操作名为“重启输入引擎”。

## 数据目录、部署与同步

可在数据目录管理中创建和切换多个目录。内部目录保存在应用自己的数据位置；
注册外部目录只记录位置，不自动搬移原文件。删除外部目录条目只解除注册。

外部目录需可被应用直接读写：Android 11 及以上通常需“所有文件访问”，
Android 6–9 需存储权限；Android 10 优先使用应用目录。云盘文档提供方不能当作原生文件路径。

部署将方案源文件生成可运行数据；Rime 用户词典同步用于交换学习数据；
应用完整备份还包含布局、主题、偏好和剪贴板等。三者不能互相替代。
用户词典同步等待实际完成，失败会返回错误；同步及备份保存的维护阶段会暂停引擎输入。

### 多个 Rime 输入法共存

每个输入法使用独立的工作目录。不要让两个仍在运行的输入法同时打开同一外部目录中的
`.userdb` 或上下文学习库。LevelDB 对工作库加独占锁，冲突时可能出现以前学过的词和
新学词都不进入候选；它不一定意味着词库丢失。关闭键盘或划掉后台页面通常不会结束输入法进程。

若已共用目录并发生此现象，在系统应用管理中强行停止其他使用者，再强行停止并重新打开
中州鹅测试。2026-10-19 的用户反馈已确认这样恢复了用户词，不需要修改引擎或清空词库。
后续将工作目录分开，通过 Rime 的同步目录和各自同步 ID 交换用户词典。
迁移前先备份，停止所有使用该工作库的输入法后再复制文件；不要删除 `LOCK` 文件来绕过占用。

## 键盘、布局与宏

在“键盘”中调整高度、分体、单手、浮动、按键反馈和工具栏；候选栏与候选窗口在“输入与候选”中分别设置。
进入“键盘自定义”编辑布局，建议先复制布局并导出备份，再更改按键和宏。

布局可包含主键盘、数字层、符号层和方案/子模式的覆盖。
按键可分别设置点击、长按、上滑和下滑动作；空格、退格等功能键有各自的手势规则。
空白占位键用于排版，不接收输入；分体布局可单独配置断点和两侧排列。
二维码分享用于单份布局，不等同于完整应用备份。

方案已有以 ID 保存的子布局时，只列实际的 ID 条目，不再额外列同一方案的显示名称；仅用名称保存的旧布局仍保留原键，不会自动重命名。

子布局下方同一行的“合成中”在左、“分体键盘布局”在右。勾选“合成中”可查看已配置的合成态按键覆盖，不会写入布局或改变实际输入状态；文本编辑面板不显示此选项。

编辑分体排列时，在“键盘结构”的行设置中勾选“本行保持连在一起”，该行按整行显示，其余行继续分体。它也会关闭该行的自动中间键复制。操作与 JSON 字段见[分体键盘](../features/keyboard/split-keyboard.md)。

行标题栏提供新增、上移、下移等操作，首末行只显示有效方向；拖动结束后恢复卡片底色。
布局、宏、弹出和字体编辑器保留主体草稿及比较基准，页面重建后可恢复已确认内容。
后台草稿尚未准备好时仍保留同步保存兜底；这不等同于保证任意时点强杀都能保存所有未确认的选择框内容。

宏可组合文本、按键、光标移动、切层和设置入口。修改后在实际输入框验证，
尤其检查 Shift、长按重复与跨层返回。旧布局保存的全局设置/引擎列表快捷方式会转到中州韵设置。
编辑点击、长按或划动的宏动作时，对话框叠加在当前页面；确认后返回原表单，最终仍需保存布局。

## 设置搜索与按键反馈

设置首页搜索支持中文名、英文别名和拼音；多个关键词需共同匹配，点结果会进入目标页并定位设置。先按要做的事搜索，例如“布局”“语音”“符号”“备份”。

首页“按需进入”末尾是“关于”，其中可打开用户手册、常见问题和版本更新；“开发者”位于“高级”页。当前首页已取消右上角三点菜单。

“键盘 → 按键反馈”可设置声音、振动等反馈。自定义音效支持 WAV、MP3、OGG、M4A、FLAC；文件不可用时回退系统音效。按键字体与候选字体分别在字体设定中管理。

空格滑动移动光标由“划动空格键以移动光标”开关控制；开始拖动后取消待触发的长按，慢速小幅拖动也可移动一格，光标步长可调至 16 dp。关闭光标开关后才使用布局里的自定义空格划动动作。
空格长按可选择切换方案、方案选单、语音或重复空格等行为；它与语言键短按切中英文是不同操作。

## 主题、字体与候选

外观页可切换和编辑主题、图标主题、字体。随机主题可重新生成，并复制为自定义主题继续修改。
内置“谷歌”图标主题提供圆角轮廓操作图标；符号面板的返回键盘键和退格键也使用当前图标主题。选择与槽位说明见[图标主题](../features/theme/icon-themes.md)。
内置图标更新仅替换仍符合旧原版尺寸的文件，已编辑或删除文件的处理规则见同页说明；谷歌主题未更新的旧识别问题已修正。
主题页的“主题库”负责选用主题，“键盘样式”中的参数对所有键盘主题生效。普通主题编辑会保留未保存草稿；返回时可保存、放弃或继续编辑。图片和主题定义在保存成功后才一起生效，失败时可重试。

主题卡片将预览、单行名称和一行编辑／导出按钮分开，不预留多余空白行；“使用中／日间／夜间”角标不会覆盖名称。新增卡片和操作区跟随设置界面配色。
候选栏可调整字号、间距、注释、序号和外观；展开候选与浮动候选窗口分别有配置入口。
字体设置中的按键、候选、注释和预编辑字体可以分别设置。

“外观 → 设置界面外观”可选择设置页明暗模式、Monet、手动配色与纯黑背景；
Android 11 及以上还可让设置页跟随键盘主题取色。外观修改即时保存并生效，没有额外的“应用”步骤。“动画与返回手势”提供页面动画、速度与预测返回设置；预测性返回默认关闭，已有用户选择会保留。

应用标识为展翅伸颈、咬住「㞢」的白鹅。Android 13 及以上的兼容桌面开启「主题图标」后，桌面图标可跟随系统壁纸配色，并保留鹅身、喙脚与「㞢」的深浅层次；应用内图标跟随设置界面配色，两者独立。Debug 图标带有完整的 Debug 字样。详见[应用图标与桌面主题图标](../features/theme/settings-appearance.md#应用图标与桌面主题图标)。

候选注释的内容由 Rime 方案控制；应用字体、颜色与间距只影响显示方式。
遇到中文缺字，先检查方案字集，再检查字体是否包含对应字符。

## 剪贴板、语音与文本编辑

便捷功能页提供剪贴板、符号和文本编辑；语音设置位于“输入与候选 → 语音输入”。
剪贴板同步和语音提供方有各自的配置、连接与权限要求，使用时查看相应页面。
这些是 Android 侧功能，不是需要另行启用的 Fcitx 原生引擎插件。
具体设置见[剪贴板同步](../features/clipboard-sync.md)和[外部语音输入](../features/voice-input.md)。

语音插件另有一条不装 APK 的路：在“语音插件设置”里导入一个 `.js` 文件，插件跑在输入法进程内的 QuickJS 里。内置通义千问、豆包、腾讯云语音识别和腾讯云实时语音翻译四个插件，导入的自定义插件与它们平级出现在同一列表，并在“首选语音输入”里作为可选引擎；密钥由宿主加密保存，脚本拿不到明文。用法与接口见 [JS 插件安装与使用](../features/voice-input-js.md)，新版接口参考提供[中文译文](../features/voice-input-js-reference-zh-CN.md)和[英文原文](../features/voice-input-js-en.md)。

当前默认分支支持带界面的 AI 文本助手：在 Kawaii Bar 或状态区添加“AI 助手”，从 **设置 → 便捷功能 → JS 插件设置** 配置服务；输入问题后点击 **发送 AI**，在面板中阅读 **AI 回复**，再点击 **确认上屏**。没有有效回复时不会因旧的“确认”事件直接关闭；请求失败保留输入，取消撤销临时预览。面板可拖动、避开键盘，并能直接接收键盘输入。三种协议均拒绝把已标记截断或拒绝的回复作为完整结果；暂时限流的自动重试会等待，并受时间预算约束。完整流程和自定义 HTTPS 端点授权见 [AI 文本助手](../features/ai-assistant.md)。

AI 面板与主界面使用同一套外观设置，输入与回复分区显示。标题旁可关闭，底部突出当前的发送或确认操作；窄屏、大字号时按钮会换行。正文独立滚动，极矮窗口则整体滚动。连接摘要默认展示主机和模型，长按可查看完整信息。

使用前在插件设置填写参数，并批准该插件的网络主机。工具栏语音键短按识别、长按切换首选引擎；选择器中的设置入口可直接打开 JS 插件设置。语音按钮可参与工具栏排列，收起键盘按钮独立保留，密码框隐藏语音按钮。换设备或卸载重装后，插件密钥需要重填。

插件设置按服务参数、密钥和授权分区，并随鉴权方式切换显示相关字段；顶部密钥数量只说明保存情况，不能证明服务已连接成功。

剪贴板短条目增加了点击区域，置顶标记更清晰；编辑窗口突出确认保存，窄屏或大字号时复制、取消和确认会按完整按钮换行。复制仍在保存成功后执行，保存失败保留草稿。

“便捷功能 → 表情和符号”可选择左侧分组栏或 Gboard 式底部栏，两种风格共用数据和最近记录。见[符号面板](../features/symbol-panel.md)。
颜文字保持单列，较长内容自动等比缩小后显示在一行内，不会换行撑高条目；网页编辑器使用相同规则，并随预览宽度重新调整。

密码输入不进入 Rime 组词，键盘直接向输入框发送按键；密码框工具栏和布局也有独立策略，语音按钮不会显示。

重启后首次解锁前，文字密码可使用之前自动同步的当前自定义布局快照；没有可用快照、密码布局无效或只有空白占位键时回退到内置 26 键，数字密码使用数字盘。按键直接输入，不要求已导入中文方案。快照只同步当前布局；字体、图标和日常中文方案仍在首次解锁后的进程重启中恢复，锁屏模式不会覆盖正常设置。相关故障见[首次解锁前启动](../troubleshooting/oem-startup.md#重启后首次解锁前无法输入)。
不同应用对光标、组合文本、编辑动作的支持可能不同，异常时记录具体应用和操作步骤。

## 备份、迁移与升级

本版恢复默认分支的包名 `org.fcitx.fcitx5.android.fx.rime`。
它可在签名相同、版本允许时覆盖原包名的旧 Fcitx 版，不能再与该版并排安装；安装前先备份。
旧直连测试包 `io.github.sandyyur.rime.direct` 与本版是两个独立应用，私有数据和应用外部文件目录不会自动迁移。
请先在测试包导出完整备份，再安装本版并恢复，检查方案、用户词库、布局与主题后再卸载测试包。
使用外部数据目录的，先强行停止旧包及其他共用者，再让新包访问独立工作目录；不要同时运行并共用用户库。

在“数据与备份”中导出完整用户数据，默认使用有密码保护的 `.fcbak`，也可明确选择兼容旧版的明文 ZIP。
页面顶部保留本次准备、保存与结果提示；失败后可再次打开错误详情。
密码没有复杂度要求，但不能为空；应用不保存密码，也无法找回。将文件保存到应用目录以外。
需要换包名、换签名或回退版本时，先备份并确认文件可以读取。
卸载会清除应用私有数据；同签名覆盖升级通常保留数据。

从旧 Fcitx 版迁移，优先在旧应用导出数据，再在中州鹅导入；
若完整备份格式不受支持，可先迁移 Rime 用户文件和单独导出的布局/主题。
不要把旧版其他引擎的词典或配置当作本版功能。

恢复完整备份前先备份当前状态。涉及外部目录时核对目标路径和最终替换范围；
恢复操作会替换目标内容。不要将公共存储根目录或包含其他用途文件的父目录作为恢复目标。

关于页的源码链接固定到正式 APK 的构建提交；用户手册与维护手册指向 `docs` 分支持续更新的文档，旧版操作需结合对应日期记录阅读。
“版本与更新”或“当前版本”可打开应用内更新器，检查 GitHub Releases、选择下载镜像并下载安装包；
关于页也会在检测到更新时提示新版本。联网失败仍显示当前版本，不影响其他设置。
导入、导出等耗时操作使用随设置主题配色的 Material 3 进度对话框；系统关闭动画时显示“请稍候”。
更新器的 hosts／镜像页面、日志与崩溃日志、方案导入、图片裁剪及剪贴板编辑也使用同一设置配色。
剪贴板编辑保持浮动窗口，布局文件选择保持透明背景上的选择弹窗。
安装与升级以成功 CI 或 Release 的实际源码、包名和签名为准；历史阶段报告不能代替当前安装包来源。
万象输入统计读取的发行代号现在为“中州鹅”，发行版本与 APK 的实际版本号一致；这不更改万象方案名。

## 隐私与数据

Rime 方案计算和用户词典在本机运行。剪贴板同步、网络语音提供方、下载或打开在线页面等
功能可能联网，取决于对应功能及提供方。请按实际需要配置。
完整备份可能包含用户词库、剪贴板历史、目录路径和同步设置。默认 `.fcbak` 使用密码加密，兼容 ZIP 不加密。
系统自动备份仅包含部分设置界面外观，完整迁移请使用手动备份；步骤与恢复中断处理见[备份与恢复](../features/backup-restore.md)。
反馈问题时先检查日志、截图和导出文件中是否包含个人输入内容。

## 保存日志与卡顿反馈

在实时日志页点击保存后，应用先冻结当前筛选结果、准备完整文件，再弹出系统保存位置选择器。
保存完成前不重复触发；取消选择后可重新保存。选择位置期间新增的日志不会改变已经冻结的这份文件。
只在文件写入并关闭成功后提示完成；保存失败会记录异常，并尽力清理新建的不完整目标。

反馈输入卡顿时，区分“刚唤起或切回输入框”“键盘已打开后的连续打字”“首次点选”“选词后立即发送”，记录具体步骤，
以及文字最终出现、迟到还是一直没有出现。`REQUEST_ACCEPTED` 只表示提交请求被接受，
不能单独证明文字已经显示或发送。分享前检查日志中的个人内容。

日志若以 `Persisted app crash` 开头，该段是此前保存的崩溃；请核对其中的时间和 `Crash build`，与后面的本次运行日志分开判断。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 没有键盘 | 检查系统是否已启用并选中中州鹅 |
| 有键盘但打不出中文 | 检查是否导入方案、当前目录与 `schema_list`，然后部署 |
| 以前学过的词、新学词都不出现 | 检查是否与其他输入法共用工作目录；强行停止其他使用者并重启中州鹅，随后分开工作目录 |
| 万象部署失败 | 核对 base 方案完整依赖、Lua、词典与模型，读取部署错误 |
| 修改开关或 YAML 没生效 | 确认当前目录和实际方案，必要时重新部署 |
| Shift 不切换中英文 | 核对方案的 `ascii_composer` 和语言键宏动作 |
| 注释和预期不一致 | 核对方案注释开关与过滤器；应用不会追加额外候选编码 |
| 无法覆盖安装 | 核对包名、签名和版本；换签名前先备份 |
| 只有很简单的测试界面 | 安装了诊断 APK，应改用带 `frontend` 名称的主应用产物 |
| 页面仍出现旧设置入口 | 确认安装的是当前分支新包，旧布局快捷方式应自动转到中州韵设置 |

反馈时提供 APK 文件名或源码提交、Android 版本、输入框所属应用、方案版本、复现步骤，
必要时附上脱敏后的配置和日志。[维护手册](../maintainer/DIRECT_RIME_MAINTAINER_GUIDE_zh-CN.md)
和[本会话交付记录](../maintainer/history/DIRECT_RIME_SESSION_2026-10-17.md)提供构建与验证细节。
