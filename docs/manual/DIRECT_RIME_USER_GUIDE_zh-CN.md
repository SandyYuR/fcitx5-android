# 中州鹅用户手册（直连 Rime 版）

适用分支：`feat/direct-rime-prototype`。应用名 **中州鹅**，包名 **`io.github.sandyyur.rime.direct`**。
本版直接使用 Rime 引擎，并提供完整键盘、候选、布局编辑器、主题和设置界面。
Rime 方案决定输入规则与词典；键盘布局决定屏幕按键和手势，两者分别设置。

## 安装与首次输入

1. 从本分支的 GitHub Actions 获取主应用。`Direct Rime experiment` 中的
   **`direct-rime-frontend-arm64-debug`** 是常用 ARM64 手机的完整界面版本。
   名称为 `direct-rime-arm64-debug` 的产物是引擎诊断工具，日常使用请选择前者。
2. 安装后，在 Android 系统设置中启用并选择“中州鹅”。其他包名的旧版可与它共存。
3. 打开应用，进入“中州韵设置”，准备下面所述的 Rime 用户文件并部署。

APK 不内置中文方案、完整词典或万象模型，只包含 Rime 通用标点、符号与按键绑定预设。
初次安装时键盘能弹出但没有中文候选，通常是还没导入方案。
覆盖升级需要同包名、同签名；本地签名包和 CI 包不保证能够互相覆盖。

## 导入方案与万象

### 从方案 ZIP 导入

进入“导入 Rime 方案”，选择方案 ZIP。压缩包根目录应直接包含 `default.yaml`
或 `default.custom.yaml`，以及方案、词典、Lua 等依赖文件，不能只放一个仓库外层目录。
导入器会创建新的数据目录并部署；原目录仍可在数据目录管理中切回。
压缩包上限为 512 MiB。方案 ZIP 与“完整用户数据备份 ZIP”用途不同。

### 手动放置方案

在“中州韵设置”打开当前用户数据目录。默认位于应用外部文件目录的 `data/rime`，
具体以当前数据目录设置为准。将方案及完整依赖放入该目录，在 `default.custom.yaml` 指定方案：

```yaml
patch:
  schema_list:
    - schema: your_schema
```

将 `your_schema` 替换为方案实际的 `schema_id`，然后在中州韵设置执行部署。
修改 YAML、词典或 Lua 后一般需要重新部署。部署期间等待“正在部署”消失后再输入。

### 你的万象配置

从 [万象官方仓库](https://github.com/amzxyz/rime-wanxiang)准备 **base / 全拼**版本，
按上游说明安装它依赖的词典、Lua 和语言模型。
在方案开关中开启“上下文调频”“简码”，选择“小字集”；模型文件按万象版本的要求放置。
“简码开启”与“使用双拼”是不同的选项，不需要为了开启简码改成双拼。

候选注释由方案自身的开关和过滤器决定。应用显示 Rime 提供的注释，
不额外把候选编码拼在后面。注释不符合预期时先确认正在使用的方案与开关，
再核对 Lua、配置补丁和部署日志。

日常方案升级请遵循万象自己的说明，并保留 `*.custom.yaml`、用户词库和手动排序数据。
本项目的性能测试使用固定官方夹具和新用户库，不能替代个人长期词频库的实机体验。

## 切换语言、方案和功能开关

- 语言键短按发送独立 Shift，中英文切换行为由方案的 `ascii_composer` 决定。
- 长按键盘语言键或使用“Rime 方案选单”切换方案；工具栏语言按钮长按可打开 Android 输入法选择器。
- 展开状态区可操作方案功能开关。二态按钮显示当前状态及目标状态；互斥选项按组显示，点开后选择。
- 切换中英文时编码区短暂显示“英文模式”或“中文模式”；切换方案时显示方案名。
  提示会自动消失，继续打字时让出编码区，切换输入框后不延续旧提示。
- 空格键在中文界面显示“中州韵（方案名）”，其他语言显示“Rime (方案名)”；
  紧凑中文标记为“㞢”。英文状态名称在中文界面显示“英文模式”。

## 设置入口

“输入与候选”内保留一个“中州韵设置”，用于方案、目录、预编辑方式、部署和同步。
候选栏和候选窗口属于界面设置，仍分别提供调整入口。
重复的“全局选项”、固定引擎的“附加组件”列表和旧快捷键隐藏开关已移除。

设置首页的搜索框支持名称、别名及拼音。可搜索“主题”“布局”“字体”“候选”“备份”等，
跳转到对应设置页。开发者页中的引擎重启操作名为“重启输入引擎”。

## 数据目录、部署与同步

可在数据目录管理中创建和切换多个目录。内部目录保存在应用自己的数据位置；
注册外部目录只记录位置，不自动搬移原文件。删除外部目录条目只解除注册。

外部目录需可被应用直接读写：Android 11 及以上通常需“所有文件访问”，
Android 6–9 需存储权限；Android 10 优先使用应用目录。云盘文档提供方不能当作原生文件路径。

部署将方案源文件生成可运行数据；Rime 用户词典同步用于交换学习数据；
应用完整备份还包含布局、主题、偏好和剪贴板等。三者不能互相替代。

## 键盘、布局与宏

在键盘设置中调整高度、分体、单手、浮动、按键反馈、工具栏和候选栏。
进入“键盘自定义”编辑布局，建议先复制布局并导出备份，再更改按键和宏。

布局可包含主键盘、数字层、符号层和方案/子模式的覆盖。
按键可分别设置点击、长按、上滑和下滑动作；空格、退格等功能键有各自的手势规则。
空白占位键用于排版，不接收输入；分体布局可单独配置断点和两侧排列。
二维码分享用于单份布局，不等同于完整应用备份。

宏可组合文本、按键、光标移动、切层和设置入口。修改后在实际输入框验证，
尤其检查 Shift、长按重复与跨层返回。旧布局保存的全局设置/引擎列表快捷方式会转到中州韵设置。

## 主题、字体与候选

外观页可切换和编辑主题、图标主题、字体。随机主题可重新生成，并复制为自定义主题继续修改。
候选栏可调整字号、间距、注释、序号和外观；展开候选与浮动候选窗口分别有配置入口。
字体设置中的按键、候选、注释和预编辑字体可以分别设置。

候选注释的内容由 Rime 方案控制；应用字体、颜色与间距只影响显示方式。
遇到中文缺字，先检查方案字集，再检查字体是否包含对应字符。

## 剪贴板、语音与文本编辑

便利工具页提供剪贴板、符号、文本编辑与语音设置。
剪贴板同步和语音提供方有各自的配置、连接与权限要求，使用时查看相应页面。
这些是 Android 侧功能，不是需要另行启用的 Fcitx 原生引擎插件。

密码输入不进入 Rime 组词，键盘直接向输入框发送按键；密码框工具栏和布局也有独立策略。
不同应用对光标、组合文本、编辑动作的支持可能不同，异常时记录具体应用和操作步骤。

## 备份、迁移与升级

在“数据与备份”中导出完整用户数据，将 ZIP 保存到应用目录以外。
需要换包名、换签名或回退版本时，先备份并确认文件可以读取。
卸载会清除应用私有数据；同签名覆盖升级通常保留数据。

从旧 Fcitx 版迁移，优先在旧应用导出数据，再在中州鹅导入；
若完整备份格式不受支持，可先迁移 Rime 用户文件和单独导出的布局/主题。
不要把旧版其他引擎的词典或配置当作本版功能。

恢复完整备份前先备份当前状态。涉及外部目录时核对目标路径和最终替换范围；
恢复操作会替换目标内容。不要将公共存储根目录或包含其他用途文件的父目录作为恢复目标。

## 隐私与数据

Rime 方案计算和用户词典在本机运行。剪贴板同步、网络语音提供方、下载或打开在线页面等
功能可能联网，取决于对应功能及提供方。请按实际需要配置。
完整备份 ZIP 未加密，可能包含用户词库、剪贴板历史、目录路径和同步设置，需自行妥善保存。
反馈问题时先检查日志、截图和导出文件中是否包含个人输入内容。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 没有键盘 | 检查系统是否已启用并选中中州鹅 |
| 有键盘但打不出中文 | 检查是否导入方案、当前目录与 `schema_list`，然后部署 |
| 万象部署失败 | 核对 base 方案完整依赖、Lua、词典与模型，读取部署错误 |
| 修改开关或 YAML 没生效 | 确认当前目录和实际方案，必要时重新部署 |
| Shift 不切换中英文 | 核对方案的 `ascii_composer` 和语言键宏动作 |
| 注释和预期不一致 | 核对方案注释开关与过滤器；应用不会追加额外候选编码 |
| 无法覆盖安装 | 核对包名、签名和版本；换签名前先备份 |
| 只有很简单的测试界面 | 安装了诊断 APK，应改用带 `frontend` 名称的主应用产物 |
| 页面仍出现旧设置入口 | 确认安装的是当前分支新包，旧布局快捷方式应自动转到中州韵设置 |

反馈时提供 APK 文件名或源码提交、Android 版本、输入框所属应用、方案版本、复现步骤，
必要时附上脱敏后的配置和日志。[维护手册](../maintainer/DIRECT_RIME_MAINTAINER_GUIDE_zh-CN.md)
和[本会话交付记录](../maintainer/DIRECT_RIME_SESSION_2026-10-17.md)提供构建与验证细节。
