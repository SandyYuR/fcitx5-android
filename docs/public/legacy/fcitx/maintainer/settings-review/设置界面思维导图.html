找不到在哪

  1. 键盘尺寸在「虚拟键盘 › 布局与尺寸」，按键圆角 / 边框 / 水波纹却在「主题 › 配置」，同类参数被拆到两处。
  2. 候选栏样式同时存在于「候选窗口」和「虚拟键盘 › 工具栏与候选栏」，两页各管一半。
  3. 浮动键盘、单手键盘只能靠点击工具栏图标打开，设置里完全没有入口。
  4. 导出主题只能长按主题卡片，界面上没有可见按钮。

名称太抽象

  1. 「增强选项」是一个空容器，里面 6 项全是编辑器入口，名字无法自解释。
  2. 「全局选项」「中州韵设置」「附加组件」三页由引擎配置树自动生成，直接显示内部键名（HiddenNotifications、Profiles 等）。
  3. 「附加组件 › 中州韵」与「中州韵设置」是同一份配置的两个入口，且没有任何说明。
  4. 图标主题的槽位弹窗直接显示 Key: capslock.none 这类内部键名。

默认与隐藏不当

  1. 「跟随系统夜间模式」默认开启，用户点任何主题都先被弹窗拦住；而真正承载手动选择的项界面上没有入口。
  2. 候选窗口 10 项样式参数平铺，不设预设，普通用户要先懂 dp/sp 才能调。
  3. 「高级」把用户数据备份与系统兼容开关混在一起。
  4. 隐藏快捷键族的开关在「高级」，而它作用的「全局选项」在另一个大类，用户想不到去那里找。

改了看不到效果

  1. 外观页预览本来就是实时的（方案 §二.6 更正：改外观项会走 refreshStyle() 重建，原“盲调”结论是错的）。
  2. 主题页与编辑器页用了两套不同的缩放实现，视觉比例不一致。
  3. Monet 颜色编辑入口在设备不支持时已改为明确提示（0.6.6，不再静默返回）。
  4. 网页编辑器配置键别名映射仍然有效（键名未改动，未做统一）。

该默认的默认

  1. 夜间模式改为三态单选：跟随系统 / 始终亮色 / 始终暗色，消除「点主题被弹窗拦住」的死结。
  2. 候选窗口 10 项样式收敛为紧凑 / 标准 / 宽松预设，细节收进「自定义」。
  3. 分体键盘已按设备类型智能给阈值，保持不动。
  4. 装饰性选项（水波纹、边框描边）默认关闭，维持现状。

该隐藏的隐藏

  1. 引擎配置中的开发者项（超时、自动保存周期、通知屏蔽）收进「显示全部选项」二级折叠。
  2. 系统兼容开关按设备能力判断决定是否出现，无关设备上完全隐藏。
  3. 标为「未实现类型」的占位行不再渲染。
  4. 快捷键族维持默认隐藏，但把这枚开关移到它所作用的页面。

命名要能自解释

  1. 「增强选项」拆解：字体 / 弹出样式归外观，键盘定义 / 数字布局归键盘工具。
  2. 「主题 › 配置」取消 tab，改为外观页内的「按键外观」分区。
  3. 22 个主题颜色项补中文名——但必须先解耦显示名与存储标识，否则会改坏已存主题。
  4. 图标主题槽位弹窗改显示中文名，不再暴露内部键。
